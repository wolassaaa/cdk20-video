# 流程的产物和文件格式（2026-11-12，韩国时间 12:10）

HKBU SCIE1007 课程作业的科普视频。这一份列每一步写出什么文件、格式是什么、谁读它。路径都在 `素材流程_out/<人>/` 下。手册 `03_素材管理员手册.md` 里提到的文件名以这里为准。

## 入口

```
_env/footage/Scripts/python.exe 镜头设计_v3/素材流程/run.py 人员素材啊/D [--steps 0,1] [--force]
```

每步写 `manifest.json`（读了哪些文件和它们的大小、修改时间，参数，产物，用时）；输入和 `config.json` 里这一步的参数没变就跳过。

## 第 0 步 `0_probe/`

| 文件 | 内容 | 谁读 |
|---|---|---|
| `probe.json` | 每个文件：时长、画幅、旋转、帧率（平均、恒不恒定）、编码、位深、颜色传递、音轨、响度、真峰值、底噪、削波；`issues` 是（问题，流程怎么处理）对 | 第 1 步、管理员 |
| `probe.md` | 同上，给人看的表 | 管理员 G0 |

## 第 1 步 `1_ident/`

| 文件 | 内容 | 谁读 |
|---|---|---|
| `words/<原文件>.words.json` | 逐词带时间的文字稿：`{"w","t0","t1","p"}`，`gain_db` 是转文字前临时拉了多少 | 第 3 步（剪点）、字幕 |
| `ident.json` | 全部认片结果：`assets`（每条素材：新名字、原文件、起止、段号、第几条、分、差别）、`files`、`missing` | 第 2 步 |
| `ident.md` | 文件 → 段号、段号 → 有哪几条、时长差，给人看 | 管理员 G1 |
| `reshoot.md` | 补拍清单：没交的段、形式不对的段、念得有出入要人判断的段 | 管理员 G2、导演 |
| `cuts.json` | 每条素材的建议入点、出点（原件里的秒）：`{"name","file","in","out","first_word","last_word","file_duration","confirmed": false}`。只是数据，不烧进片子；第 5 步上片时才用 | 管理员 G7、第 5 步 |
| `names.json` | `D_cam_1-05_t1_raw.mp4 → {原文件, in, out}` 的映射（不拷文件） | 第 3、4 步 |
| `thumbs/<新名字>_thumb.jpg` | 缩略图条：这条素材开头、中间、结尾各 2 帧，共 6 帧，已转成普通色彩 | 管理员 G1（看图） |
| `library.json` | 每条素材一行：`name, file, class, beat, take, in_file, duration, script_seconds, spec, score, status, problems, note, said, thumb` | 管理员 G1 |
| `review.json` | **管理员写回的**，格式见下 | 第 2 步、第 6 步 |

同时重写 `镜头设计_v3/素材流程/素材对照表.csv` 和 `.md` 里这个人的行（列照 `04_命名规则.md`）。别人（GLM、导演）改过的"状态 / 谁定的 / 备注"，只要这条素材的原文件和起止没变，重跑时保留。

### `review.json` 的格式

```json
{
 "person": "D",
 "reviewer": "GLM glm-5.3-flash",
 "made": "2026-11-12 13:00 韩国时间",
 "items": [
  {"name": "D_cam_1-05_t1", "verdict": "ok",     "reason": "缩略图是 D 本人在说话，文字和 1-05 台词一致，100 分"},
  {"name": "D_cam_3-06_t1", "verdict": "unsure", "reason": "开头少了 So，念成 a really strong suspect，意思没变，要导演定"},
  {"name": "D_ext_x02_t1",  "verdict": "reject", "reason": "低头写字的空镜，不是剧本段，片尾也用不上"}
 ]
}
```

- `verdict` 只能是 `ok` / `unsure` / `reject`；`reason` 一句话。
- `name` 必须和 `library.json` 里的一致。没写到的素材按 `unsure` 算。
- 第 2 步选条只在 `ok` 的里面排；`reject` 的不进后面的步骤；`unsure` 的列给导演。

## 第 3 步 `3_audio/`（还没做）

## 第 4 步 `4_video/`（还没做）
