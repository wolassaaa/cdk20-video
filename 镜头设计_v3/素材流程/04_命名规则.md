# 素材统一命名和对照表（2026-11-12，韩国时间 03:00）

HKBU SCIE1007 课程作业的科普视频。组员交来的文件名各式各样（乱码、"第一段"）。这一份定统一的名字，和一张"文件对到哪句台词"的对照表。原件永远不改名，新名字只用在流程的产物上。

## 名字的样子

```
<人>_<类>_<段号>_t<条>_<态>.<后缀>
```

| 段 | 取值 | 说明 |
|---|---|---|
| 人 | `A` `B` `C` `D` | 剧本里的四个角色。不写真名和学号 |
| 类 | `cam` | 出镜视频 |
|  | `vo` | 画外音录音 |
|  | `ext` | 剧本以外的：空镜、片尾的笑脸和挥手 |
|  | `unk` | 没认出来是什么，等人看 |
| 段号 | `1-05` 这样 | 照剧本的段号。`ext` 用 `x01` `x02`，`unk` 用 `u01` `u02` |
| 条 | `t1` `t2` … | 同一段的第几条，按录的先后排 |
| 态 | `raw` | 指回原件（只是一条映射，不拷文件） |
|  | `std` | 标准片：整条、普通色彩、恒定 60 帧、抠好像放在干净底上 |
|  | `mat` | 抠像的蒙版 |
|  | `aud` | 处理好的声音（48 kHz WAV，统一响度） |
|  | `thumb` | 缩略图条 |

例子：

- `D_cam_1-05_t1_std.mp4`：D 出镜的 1-05 段第 1 条，标准片
- `D_cam_1-05_t1_aud.wav`：同一条的声音
- `D_vo_3-02_t2_aud.wav`：D 画外音 3-02 段第 2 条
- `D_ext_x01_t1_std.mp4`：D 的一条空镜

名字里只用英文字母、数字、短横和下划线，哪个软件都认。

## 一个原件里有好几段怎么办

一条录音里可能连着念了几段，或者同一段念了两遍。做法：原件不切；每一段、每一条各算一条素材，记下它在原件里的起止时间。处理声音时按这个起止各出一个 `aud` 文件。视频同理。

## 对照表

文件：`镜头设计_v3/素材流程/素材对照表.csv`（给程序读）和 `素材对照表.md`（给人看），由流程第 1 步生成，每次重跑整张重写。一条素材一行：

| 列 | 内容 |
|---|---|
| 新名字 | 不带态和后缀的那一段，比如 `D_cam_1-05_t1` |
| 原文件 | 组员交来时的文件名 |
| 原件里的起止 | 秒 |
| 人 | A / B / C / D |
| 类 | cam / vo / ext / unk |
| 段号 | 1-05 |
| 片中时间 | 剧本里这一段的起止 |
| 台词 | 剧本里这一段的英文原文，全文 |
| 实际念的 | 转出来的文字 |
| 差别 | 漏词、多词、念成别的词；没有就空着 |
| 第几条 | 1、2、3 |
| 真实时长 / 剧本时长 | 秒 |
| 匹配分 | 0 到 100 |
| 状态 | 选用 / 备用 / 存疑 / 不能用 / 待看 |
| 谁定的 | 规则 / GLM / 导演 |
| 备注 | 一句话 |

对照表不含组员的真名和学号，可以进 GitHub。原件和处理后的片子都不进。
