# 素材流程要的环境和工具 · 计划表（2026-11-12，韩国时间 03:00）

HKBU SCIE1007 课程作业的科普视频。这一份是计划：要装什么、各管哪件事、大概占多少地方。实际装了什么、什么版本、怎么重建，看工人写的 `env.md`。占用的数是估的。

| 管什么 | 要什么 | 估占用 |
|---|---|---|
| 底座 | Python 3.11 环境（uv），带显卡支持的 PyTorch | 5–6 GB |
| 转码、转颜色、量响度 | 完整版 ffmpeg（带 zscale、libplacebo、h264_nvenc） | 0.2 GB |
| 语音转文字 | faster-whisper large-v3 | 3 GB |
| 字幕对时间 | 强制对齐的库和模型 | 1–1.5 GB |
| 语音增强、降噪 | 两三个候选模型，比完留一个 | 1–2 GB |
| 抠像 | 两三个候选模型，比完留一个 | 1–2 GB |
| 找脸、皮肤区域 | 人脸关键点的库 | 0.5 GB |
| 美颜 | 不另装模型：用脸的蒙版加常规的图像处理做磨皮、祛痘 | 0 |
| 调色、色温 | 不另装：ffmpeg 加 numpy | 0 |
| 文字和看图的模型 | 不装在本机：走 API，钥匙在 `_env/keys.env` | 0 |
| 产物 | 每人约 100–200 秒素材的标准片、蒙版、声音 | 每人 3–6 GB |

合计：环境约 12–17 GB，四个人的产物约 12–24 GB。11-12 凌晨量到 D 盘空 65 GB（环境已经装了 6 GB），C 盘空 38 GB。够用，不用删游戏。

如果后面要试更大的模型（比如更好的抠像或语音增强），每个再多 2–5 GB，到时再看。
