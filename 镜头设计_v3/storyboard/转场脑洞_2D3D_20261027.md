# 2D ↔ 3D 大转场脑洞 + 舞台工程参考（2026-10-27 记录，后面再做）

方向：多参考舞台工程（演唱会 LED 大屏、沉浸式装置），用 Blender（+ TD）做一批"不讲道理"的 2D 和 3D 互相变身的转场。原则还是同一个：**下一个画面从上一个画面里的同一个东西长出来**，不用淡入淡出糊过去。

## 一、要去查的舞台工程参考（待查证，查完再补链接和具体做法）
- 演唱会舞美设计师 / 工作室：Es Devlin、Moment Factory、1024 Architecture、Treatment Studio（拉斯维加斯 Sphere 的 U2 演出视觉）、United Visual Artists。
- 数据 / 生成艺术：池田亮司（Ryoji Ikeda）、Refik Anadol、Max Cooper 的现场视觉。
- The Weeknd 巡演舞台（After Hours til Dawn）、NewJeans 演出 VCR。
- TouchDesigner 做大型巡演的案例（研究报告里有 RHCP 2022 的实证）。
- 重点看：大屏和实体舞台怎么配合、2D 图形怎么"立"起来变成 3D、镜头怎么穿过画面。

## 二、转场点子（对应分镜 v3 编号）
1. **纸片折成器官**（SQ05 → SQ06）：标题卡那张米白纸被折起来，折痕变成肝脏的轮廓，纸面翻过去就是 3D 线稿肝脏。Blender 布料或折纸动画 + Line Art。
2. **手绘线"立起来"**（SQ06）：一笔平面的墨线肝脏轮廓，镜头一转，发现它其实是 3D 肝脏的边缘线，后面的血管树跟着亮起。2D 描边和 3D Line Art 用同一个轮廓对齐。
3. **钥匙孔穿越**（SQ11 → SQ12）：手绘的平面钥匙孔，镜头直接推进去，穿过去就是真实 CDK20 的 3D 口袋（口袋形状和手绘钥匙孔对齐）。
4. **点云坍缩成墨线**（SQ15，W2）：电青 AlphaFold 点云（TD）在一拍上坍缩成 Blender 的手绘缎带线稿——SIGNAL 变 INK，一次对撞。
5. **分子从纸面浮起来**（SQ20 → SQ22）：论文图 5 / 图 7 的反相原图（平的），里面 001 的骨架一根根键从纸面立起来，变成 3D 球棍模型落进口袋。
6. **漏斗变隧道**（SQ18，W3）：2D 计数漏斗旋转 90° 变成一条 3D 隧道，镜头沿着 8,918 → 54 → 7 一路冲进去，出口就是那 1 个分子。
7. **血管变电路再变回来**（SQ14 / SQ17）：TD 红色血管流线拉直变成电青数据线（身体 → 计算），再弯回去变回血管。
8. **培养皿是一个舞台**（SQ23）：俯视的 2D 手绘培养皿，镜头下压变成侧视的圆形舞台，细胞在 LED 地面上"演出"。
9. **四个角是四块屏幕**（全片 / 片尾）：口播纸片像舞台上的四块侧屏，片尾镜头拉远，四块屏和中间的 TD 血管大屏组成一个完整的"舞台"。
10. **阶梯变成真的台阶**（SQ24）：手绘证据阶梯在 3D 里变成一段真实的楼梯，镜头往上走，走到第 4 级停住，第 5、6 级是虚线、悬空。

## 三、做法备注
- 2D 和 3D 对齐的关键：Blender 相机和 Remotion 画面用同一套坐标，或者从 Blender 导出每帧的 2D 投影坐标（之前 T3 已验证过 `--anchors-only`）。
- 墨线化的 3D：Blender Grease Pencil v3 + Line Art（已在 blender_lineart 测通）；TD 用边缘检测 + 反馈。
- 每个转场先做 3–5 秒小样，挑 3–4 个最狠的放进 HYPE 段（片头、章节切换、W2–W4 展示时刻）。
