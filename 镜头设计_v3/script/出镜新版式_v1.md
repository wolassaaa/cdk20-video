# 出镜新版式 v1（2026-11-14，韩国时间 00:20）

HKBU SCIE1007 课程作业的科普视频：出镜段的画面版式。导演 11-13 定方向，11-14 采纳 Fable 子代理的建议。

## 版式
- 手绘肝细胞（米白纸底）铺满 16:9，人不加框，贴画面下沿站。
- 默认人在左（中心在画宽 30%），动效在右。
- 头的大小统一：按第 4 步算出的胸口以上框（眼睛在三分之一处、头顶留 10%）定比例，这个框高 = 画高 86%。
- 程序：`素材流程/cellbg.py` 出 `<名>_wide.mp4`（3840×2160 60 帧），粗剪 `build_cut.py` 规则 R7。

## 对话段站位（config.json video.layout.side）
- 一个画面只放一个人，不同框。底不切，只换人。问句最后一个词后 2–3 帧切。
- 提问 / 插话的人站右，回答的人站左；对话一结束回到默认左。
- 现在设成站右：1-05 D、4-11 D、5-06 B、6-04 D、8-06 D。
- 眼神方向不对时可左右翻转画面；C 的 T 恤有字，C 不翻。

## 和深色动画段的衔接（待做）
- 出镜 → 动画：墨从动效一侧漫过画面，0.6–0.8 秒，湿边；墨到七成时下一段的青线、朱红线已浮出。
- 动画 → 出镜：墨退开 0.5 秒，退过身体后 4 帧内人出现。
- 出镜段最后一个墨线道具就是下一段动画的第一个主体（1-07 时间线 → 1-08 流程；4-12 → 对接打分）。
- 朱红、青色用动画段的原色值；青色每段最多一处。细胞底不压暗，只加人身后的淡纸面阴影。
