## S3 · 背景：锁、钥匙，以及为什么是 CDK20 · 04:27–06:40 · 主讲 D

**本段作用：** 先用“锁和钥匙”类比，再引出蛋白、靶点、候选分子、选择性等术语；说明为什么选 CDK20（2011 年香港研究 + 2023 年 AI 靶点排序），引出“没有锁的照片”的难题。

**画面概要：** 墙上手绘锁孔开场；细胞→蛋白→口袋的手绘缩放（标注“示意”）；真实 AlphaFold CDK20 模型灰色缎带缓慢旋转，用墨圈标出 ATP 口袋；52 个墨线计数、36 个填实；十条数据流像血管汇入一条主干；手写 20 行候选名单，笔圈出 CDK20。

**3-01 · 04:27–04:31 · D · 出镜**

要理解这个故事，先想象一把锁和一把钥匙。

**3-02 · 04:31–04:45 · D · 画外音**

在我们的细胞里，很多工作是由蛋白质完成的。大多数药物的作用方式，是紧紧结合在某一个蛋白上，改变它的作用。药物分子嵌进蛋白上的一个口袋，就像钥匙插进锁里。

**3-03 · 04:45–05:08 · D · 画外音**

这个“锁和钥匙”的想法已经有一百多年历史。在药物发现中，锁叫做“靶点”，也就是我们想影响的蛋白。钥匙就是“候选分子”。好钥匙要紧紧配合自己的锁，又不会打开别的锁。后面这一点叫做“选择性”。

**3-04 · 05:08–05:23 · D · 画外音**

我们的锁是CDK20。它是一种酶，也就是在细胞里负责某项化学工作的蛋白。它的“锁孔”是一个口袋，平时用来抓住一种叫ATP的小分子。

**3-05 · 05:23–05:47 · D · 画外音**

为什么选这把锁？还记得那个香港团队吗？在52个与配对非肿瘤组织比较的肝肿瘤中，有36个的CDK20较高。CDK20高的病人，肿瘤往往分期更晚、生存时间更短。而在肝癌细胞中降低CDK20，细胞就长得更慢。

**3-06 · 05:47–05:55 · D · 出镜**

但关联不等于证明。CDK20只是一把可能的锁，不是肝癌的唯一成因。

**3-07 · 05:55–06:16 · B · 画外音**

在2023年的研究里，一个叫PandaOmics的AI平台帮忙挑选了这把锁。它汇总了10组肝癌数据——一千多份肿瘤样本和数百份健康对照——再加上研究文献中的证据，给可能的靶点排序。

**3-08 · 06:16–06:31 · B · 画外音**

之后研究人员再筛选这个排名，人工审阅前20名。CDK20排在最前：它和肝癌关联强、没有针对它的获批药物，而且没有实验测定的三维结构。

**3-09 · 06:31–06:38 · B · 出镜**

最后一点正是难题：没有锁的照片，要怎么设计钥匙？

## S4 · 方法：四种计算工具（目标一） · 06:40–09:42 · 主讲 B

**本段作用：** 目标一：逐步讲结构预测（含低可信尾巴的处理）、生成式设计（含平台筛选器）、对接 / 虚拟筛选与聚类，最后归纳四种工具。

**画面概要：** 一串墨点珠链折叠成真实的 CDK20 缎带，按 AlphaFold 可信度上色；低可信尾巴（303–346）用橙墨标出、Arg305 卡在口袋里，镜头推进；尾巴化成 TD 粒子像血流一样流走；几十条平行流线各自“画”出分子骨架；8,918 个墨点组成的墙被一道波扫过；聚类后 54 个前移、7 个加粗。

**4-01 · 06:40–06:54 · B · 画外音**

通常，蛋白质的形状要靠困难的实验室实验来测定，已知蛋白中只有一小部分被测过。所以第一个工具是结构预测。

**4-02 · 06:54–07:12 · B · 画外音**

把蛋白质想象成一串长长的珠子，它会折叠成三维形状。珠子的排列顺序就是它的“序列”。AlphaFold从已知结构中学会了序列怎样折叠，所以它能预测形状，并给每个部分一个可信度分数。

**4-03 · 07:12–07:33 · B · 画外音**

团队从公开的AlphaFold数据库下载了CDK20的预测结构。大部分可信度很高，但一端的“尾巴”可信度很低，而且在模型里，它正好堵住了锁孔：尾巴上的一个组成单元就卡在ATP口袋里。

**4-04 · 07:33–07:38 · B · 出镜**

于是科学家把尾巴切掉了。电脑的猜测需要人来把关。

**4-05 · 07:38–07:49 · B · 画外音**

他们保留第1到第302个单元，去掉其余部分。预测结构是有用的模型，但不是照片。

**4-06 · 07:49–08:08 · B · 画外音**

接下来，想象不是在一抽屉现成的钥匙里翻找，而是为这个锁孔直接“切”出全新的钥匙。这就是第二个工具：生成式设计。团队用的是一个叫Chemistry42的平台，它同时运行几十个AI模型。

**4-07 · 08:08–08:18 · B · 画外音**

他们把口袋的形状和大小告诉平台，并定了一条规则：每个设计都必须抓住口袋里一个特定位置，叫做“铰链”。

**4-08 · 08:18–08:37 · B · 画外音**

平台还有内置的筛选器：去掉带有活泼、不稳定或可能有毒化学基团的设计，并给每个设计打分——它像不像药、合成起来容不容易。这些只是早期的电脑检查，不是安全性测试。

**4-09 · 08:37–09:01 · A · 画外音**

这一切产生了8918个新设计，多到实验室根本做不完。于是团队在虚拟的锁里逐一试钥匙。这就是第三个工具——“对接”：电脑预测每个分子可能怎样待在口袋里，并给吻合程度打分。对一大批分子这样做，叫做“虚拟筛选”。

**4-10 · 09:01–09:04 · A · 出镜**

但对接分数高只是线索，不是证明。

**4-11 · 09:04–09:18 · A · 画外音**

团队还把相似的设计归成一组——这叫“聚类”——以便挑出多样化的一批。他们先入围54个，再由化学家挑出7个真正合成。

**4-12 · 09:18–09:40 · A · 画外音**

所以，就第一个目标而言：这个案例用了四种计算工具——挖掘疾病数据来选靶点、预测蛋白形状、生成新分子，以及用对接给分子排序。课程讲义还列出了其他方法，比如分子动力学，但这项研究没有报告使用它们。

## S5 · 结果：从 8,918 个设计到一个候选分子（目标二的证据） · 09:42–12:25 · 主讲 C

**本段作用：** 案例结果与数字：30 天得到首个命中物 001（能结合但阻断弱），第二轮得到 048（结合、酶、细胞结果），并说明每个数字的含义和边界。

**画面概要：** 一排 7 个真实分子骨架（按论文图 5 重画）；001 和 048 用论文给出的预测结合姿态放进真实 CDK20 口袋（标注“预测姿态”）；Kd、IC50 用清楚的 2D 数字和误差显示；钥匙插进锁、转不动/转动的手绘动画；一条 TD 回流血管把实验数据带回设计端；两皿手绘细胞（标注示意）对比 Huh7 与 HEK293。

**5-01 · 09:42–10:00 · C · 画外音**

那么，这7个分子有没有成功的？团队先测试每个分子是否真的能结合CDK20。结合的紧密程度用Kd表示：大致是抓住一半蛋白所需的分子量。数字越低，抓得越紧。

**5-02 · 10:00–10:04 · C · 出镜**

7个里有1个脱颖而出，它叫001。

**5-03 · 10:04–10:24 · C · 画外音**

001与CDK20结合的Kd是9.2微摩尔。这是真实的实验测量，不是电脑分数。论文报告说，从选定靶点，经过设计、合成和测试，到得到这个首个“命中物”，用了30天。

**5-04 · 10:24–10:37 · C · 画外音**

30天听起来很快。但这是得到第一个能结合的分子用的30天，不是做出一种药。而且没有不用AI的对照组，所以我们说不出到底快了多少。

**5-05 · 10:37–11:00 · C · 画外音**

还有一个问题：粘在锁上，不等于能把锁卡住。第二项测试看的是：001能多大程度阻断CDK20的实际工作。这就是IC50：把酶活性降低一半所需的量，越低越好。001的IC50高于6微摩尔，作用很弱。

**5-06 · 11:00–11:04 · C · 出镜**

钥匙插进去了，但几乎转不动。

**5-07 · 11:04–11:21 · C · 画外音**

于是团队利用学到的东西：实验数据，加上电脑对001在口袋里姿态的预测，指导了第二轮设计。16个新设计，合成并测试了6个，全部在首个命中后的30天内完成。

**5-08 · 11:21–11:31 · C · 画外音**

其中一个叫048，结合紧密程度提高了约15倍：Kd约为570纳摩尔（屏幕显示准确值566.7）。

**5-09 · 11:31–11:40 · C · 画外音**

在酶活性测试中，048只要33.4纳摩尔就能把CDK20的活性降低一半。

**5-10 · 11:40–11:41 · C · 出镜**

这一次，钥匙转动了。

**5-11 · 11:41–12:08 · C · 画外音**

接着是活细胞测试。细胞与048共处三天后，研究人员测量了活细胞发出的信号。在CDK20含量很高的Huh7肝癌细胞中，信号在约210纳摩尔时减半；作为对照的HEK293细胞系则需要约1700纳摩尔，大约多8倍（屏幕显示准确值208.7与1,706.7）。

**5-12 · 12:08–12:23 · D · 画外音**

所以048对这些肝癌细胞的作用更强。但HEK293并不是正常肝细胞，而且单一的细胞测试也不能证明这种作用只来自CDK20。

## S6 · 评价：好处与局限（目标二的判断） · 12:25–14:59 · 主讲 D

**本段作用：** 把结果放上“证据梯子”；按健康 / 经济 / 伦理 / 环境区分“已展示”和“仅可能”的好处；提出四个具体局限。

**画面概要：** 手绘证据梯子自下而上点亮到第四级，第五、六级（动物、病人）保持虚线并标“未报告”；四格墨线网格（健康/经济/伦理/环境），每格分“已展示 | 可能、未测量”；只有一名选手的跑道；“8,918 ÷ 7”写出后被划掉；人体轮廓里的器官留白加问号。

**6-01 · 12:25–12:48 · D · 画外音**

我们把证据放到一架梯子上。第一级：电脑预测。第二级：与蛋白结合。第三级：阻断酶的活性。第四级：对细胞的作用。048已经到了第四级。第五、六级——动物和病人——还是空的。2023年的研究没有报告这些分子的动物或人体测试。

**6-02 · 12:48–12:54 · D · 出镜**
