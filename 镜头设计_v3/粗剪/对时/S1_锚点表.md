# S1 锚点表

HKBU SCIE1007 课程作业的科普视频（英文）。这是剪辑对时的试点：量 S1 非出镜段的动画动作比录音里说到它的词早或晚多少。不改任何成片。

## 怎么量的

- 时间全部是粗剪 `cut_v3.mp4`（1080p30）的秒。画面在 `S1S2_table_2.mp4` 文件里的秒 = old_start + (粗剪秒 − new_start)，JSON 里的 `src_t`。
- 画面时间：每 0.5 秒抽帧（`_抽帧/<段>.jpg`）找到动作，再在 ±0.3 秒内取帧差上升最陡的一帧（`motion.py`、`anchors.py`）。文字类动作（1,412、1-09 六个站名、1-10 Nobel 一组、~3 in 10）改用字区深色像素数实测（`ink.py`），到 0.1 秒。3D 镜头起落、液体流动这类慢动作的"开始"本身有 ±0.2 秒的含糊。
- 词时间：`素材流程_out/<人>/5_place/place.json` 的词级时间，按 `build_cut.condense` 同样的头部裁剪（首词前留 0.15 秒）和停顿压缩（1-09 压了 5 处，共 2.44 秒，每个接口另吃 0.02 秒交叉淡化）换算到粗剪（`words_in_cut.py` → `words_S1.json`）。
- 换算抽查（ffmpeg silencedetect，-40 dB）：1-02 "Here," 算 13.07 / 实测静音结束 13.05；1-02 "Worldwide," 20.52 / 20.50；1-09 "Improve" 89.21 / 89.20。三处误差 ≤ 0.03 秒。（另两处 1-09 "Every"、"Any" 差 0.10–0.11 秒，是静音检测被换气声提前触发。）
- 偏差 = 画面时间 − 词时间。负数 = 画面抢在词前面。
- "顺序冲突"：画面里两件事的先后和台词里相反（例如 1-10 先长模型、后出 Nobel 字，台词是先 Nobel 后 AlphaFold），变速改不了先后，只能挑一组单调的当锚点，其余跟着走。
- W0（2 秒）、W1（标题卡）没有台词，不对词；W1 已在粗剪里删掉 8–14 秒静止段。
