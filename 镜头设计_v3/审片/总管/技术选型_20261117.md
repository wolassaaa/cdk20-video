产物：`镜头设计_v3/审片/总管/技术选型_20261117/`（5 个 mp4、对比_f130/f210/f340.png、data/ 下的两次渲染逐帧一致性记录）。

## 二、画面质感（看 对比_f210.png）

- **Remotion / HyperFrames**：两者画面几乎一样，干净的 2.5D 纸盒加球，字是 Instrument Serif，锐利、排版准。但光影是假的，纸盒像贴图，"PPT 感"在这里最重。
- **Blender 5.3**：真实的接触阴影、软光，球面形变，是唯一"像在桌面上的实物"的版本，和已批准的 S1/S2 三维台面镜头同一种质感。
- **TD 单独**：适合程序化纹理和粒子，做主体叙事动画不合适，事件漏得最多。
- **TD + Blender**：Blender 主体加 TD 生成的蓝色雾状体积，层次最丰富。雾的颗粒还偏粗，要调，但方向对。

## 三、Blender 5.3 兼容性

可以用。`G:/software/blender-5.3`（5.3.0，2026-11-10 构建）跑完整个 fast_render 流程：烘焙 0.3 s、Alembic 导出、Cycles 渲 344 帧，返回码 0，没有报错。日志里只有一条 Alembic 警告（`unable to export /runner-0/runner as instance`），对成片没有影响。新镜头一律用 5.3；5.1.2 只留着重渲旧镜头。注意：Cycles 两次渲染不是逐像素一致，最终版请固定采样种子，不要拿两次渲染做逐像素比对。

## 四、和映射表对接的难度

- **Remotion**：最容易。keys JSON 直接 import，帧号就是 `useCurrentFrame()`，改一个词的时间只要改 JSON 再重渲，十几秒出结果。
- **HyperFrames**：和 Remotion 一样容易，而且两次渲染完全一致。缺点是速度只有 Remotion 的三分之一左右，项目里已有大量 Remotion 代码，两套并存没有好处。
- **Blender**：中等。要用 Python 把 keys 写成关键帧（已有 bl_* 脚本模式），每次改时间都要重烘焙重渲，比 Remotion 慢十几倍。
- **TD**：最难。逐词事件要靠 Timer/CHOP 手搭，这次漏了三个。适合吃一条连续曲线（如句子能量、拍点），不适合吃离散事件表。

## 五、统一架构建议（结论）

**一条原则：Blender 管"东西"，Remotion 管"字"，TD 管"空气和质地"，最后在 Remotion 里按音频时间合成。**

1. **Blender 5.3：所有三维主体和台面。** 分子、蛋白口袋、纸卡实物、机位运动都放在这里。理由：只有它有真实光影，导演已批准的 S1/S2 台面和 W2/W3 锁钥都是这个质感；对词 6/6 通过。成本是 0.7 s/帧（1080p），按 4K 配方算，全片要按 `排片表.md` 排队。
2. **Remotion：所有文字、数字卡、字幕、出处行、人像旁图形，以及最终合成。** 理由：最快（0.04 s/帧）、最贴映射表、字最锐利、已有代码最多。HyperFrames 不再引入：画面一样，速度慢 3 倍，多一套工具只会增加维护。
3. **TouchDesigner：负责"质感层"，这是一个实在的、全片都会用到的角色。** 具体管三件事：
   - **体积和氛围**：雾、光晕、溶液、粒子（本次蓝雾就是这一层），按 keys 里的事件帧或句子包络驱动强度，渲成带 alpha 的序列，叠在 Blender 之上；
   - **转场**：段与段之间的液体/墨晕/溶解转场（替代被否掉的生硬黑墨转场），用 TD 做程序化遮罩，交给 Remotion 当 matte；
   - **材质贴图生成**：给 Blender 用的噪声、法线、流动贴图（例如分子表面的流动光泽），离线导出 PNG/EXR 序列再贴回 Blender。
   TD 不做主体动画、不做文字。理由：它单独做主体时漏了一半事件，但当叠加层时（TD+Blender）对词 6/6 通过、画面最丰富，速度也快（0.05 s/帧），所以把它放在它擅长、出错不影响对词的位置。
4. **AE 只做实拍素材调色、抠像和跟踪**（不变）。

## 六、全片从第一帧到最后一帧的流程

1. **音频定时间轴**：配音 → 词级时间 → `映射/keys/<段>.json`（resolve.py）。之后所有工具只读这一份，不手填帧号。
2. **Blender 出主体层**：脚本读 keys 写关键帧 → 先渲 1080p 草稿 → check_sync 过 6/6 → 用 5.3 跑 fast_render。
3. **TD 出质感层**：同一份 keys 驱动雾/粒子/转场遮罩/贴图，渲带 alpha 的序列（贴图回到第 2 步）。
4. **Remotion 出文字层并合成**：读 keys 放字卡、数字、字幕、出处；把 Blender 层、TD 层、实拍层按音频对齐叠起来，输出该段成片。
5. **每段自检**：check_sync（S1–S4）加 `审片/导演标准_审片用.md`，自己先过一遍，过了再给导演看。
6. **全片拼接**：Remotion 主合成按段拼接，在接缝处查转场和对词；1080p 全部打磨好之后才上 4K60。

这个流程里每一层都能单独重渲：改字只重渲 Remotion，改雾只重渲 TD，只有改主体才动最慢的 Blender。
