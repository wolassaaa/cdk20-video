## 不能破的规矩

1. **不闪。** 不加逐帧颗粒，不做频闪。这是导演定的。
2. **真实数据。** 蛋白、口袋、肝只用下面列的文件。不画假分子，不编数字，不改数字，± 不能丢。
3. **证据等级要看得出。** 实测、AI 预测、我们自己的对接、示意图四种，靠形状或线型也要分得开，不能只靠颜色。可以换表现方式，但这四种区别不能丢。
4. **人是暖的。** 组员各自用手机拍，光线和背景都不可控，所以这个方向要能接住普通手机素材。质感靠后期。
5. **字要读得清。** 正文不小于 36 px（1080p），对比度够。
6. **只学方法。** 可以看真实的摄影、电影和舞台作品，不用任何人的标志、字体、版式和素材，不用 The Weeknd 的视觉元素。
7. **参考图不存到本地。** 在浏览器里看就好。
8. **字体用 Google Fonts 上 SIL OFL 的。** 在方向说明里写明用了哪款。
9. **不写剧本里没有的科学说法。** `pigment` 方向的颜色说明除外，只能用一般百科查得到的常识，并写明出处。

## 渲染排队

CPU 和内存紧张，显卡同一时间最多跑两个 Blender。每条 Blender 命令都用下面的方式跑，线程数 `-t 4`：

```bash
bash "D:/。hkbu/molecular science/镜头设计_v3/styleframes/art/gpu_slot.sh" "D:/software/tools/blender.exe" -b -t 4 -P 脚本.py -- 参数
```

看图阶段用 1080p，单张渲染控制在 3 分钟以内。Cycles 或 EEVEE 自选，能用 EEVEE 就用。
