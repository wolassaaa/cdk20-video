# 锁的三种新样子（静帧，11-10）

HKBU SCIE1007 课程作业的科普视频。这一步给片里"锁"这个道具出三种新样子的静帧，供导演挑方向。只有静帧，没做动画，现有镜头一个没改。

对照图：`lock_compare.jpg`（上排近景，下排 4-10 的中景机位；最左一列 now 是现版，同一个机位重渲的）。
单张：`lock_A_close.png`、`lock_A_mid.png`，B、C 同理；现版是 `lock_now_close.png`、`lock_now_mid.png`。都是 1920×1080。

三种的锁孔都是现版同一个轮廓（`frames/pocket_outline.json`），锁的位置和大小也照现版。台面、灯光、液体金属钥匙都是 W3 定稿原样借来的。没开景深。

## A 暗铬锁体

一整块暗铬，和钥匙同一种金属。正面一个圆形锁芯，比锁体高出一点；锁芯上切出口袋形锁孔，孔底是发光的克莱因蓝。没有刻度环。

看下来的毛病：
- 正面是镜子，照出台面的格子和钥匙自己的倒影，近景里锁孔右上方有一小块钥匙的倒影，有点乱。把正面做成细拉丝能去掉，这一版没做。
- 顶面照到暗场，是一条纯黑，偏重。
- 锁孔的蓝被孔壁挡掉一部分，中景里蓝色的形状不完整。

## B 蓝玻璃锁体

一块克莱因蓝的厚玻璃。口袋形空腔从正面挖进去，背面留一层；空腔里衬了一层墨黑的薄壳，所以正面看锁孔是黑的。孔口镶一圈细的暗铬线。没有刻度环。

看下来的毛病：
- 玻璃块里面的折射很花，正面一个大"X"形的亮暗块，抢锁孔。把玻璃做薄试过一次（厚度从 0.09 减到 0.064），好一点，还是花。
- 原想的"透过玻璃看见空腔通到深处"基本看不出来，只有正面的黑锁孔看得清。
- 第一遍没衬黑壳，空腔完全读不出来，所以加了黑壳。

## C 白卡改良

白卡和黑色口袋孔留着，卡加厚：白面板后面是一块墨黑的芯，锁孔是真的切口，看得见白色切面，往里是黑的。三圈刻度环换成一圈细的暗铬环，贴在卡面上，不带刻度。Met84 的蓝点留着（A、B 上没放）。

看下来的毛病：
- 最干净，但和现版最像，更像一块面板，"锁"的感觉不比现版强多少。
- 和液体金属的联系只靠那一圈细环。
- 暗铬环下沿照到 CDK20，有一小段蓝边。

## 三种都有的

- 锁是悬着的：现版的锁本来就悬在 CDK20 前上方，底边离台面约 0.75（CDK20 模型顶在 0.57）。新样子照这个位置放，所以也悬着。A、B 是实心的一块，悬着比纸卡更显眼。要它落到台面上，W3 和 4-10 里锁的位置都得跟着改；`bl_lock.py` 里留了 `LOCK_DROP=1` 可以先看一眼落地的样子，这次没渲。
- 钥匙比锁小很多（钥匙长约 0.2，锁孔宽约 0.26），比 W3 里悬着的那把只放大了一成多。
- 中景里两格钥匙地毯只看得见圆头，这是 W3 的老毛病（4-10 里单独修过），不是这次弄的。
- 近景下沿切到了 CDK20 模型的顶。

## 穿模和悬空

搭完后量过（`LOCK CHECK`）：钥匙离锁最近 0.199（近景）和 0.359（中景），四种都一样量级；钥匙最低点离台面 0.965。钥匙没碰锁。六张图里没看到穿模。锁和钥匙都悬在空中；中景里 CDK20 那一格有一片影子，但锁自己的影子我没能单独认出来，钥匙的影子也没找到。

## 怎么重渲

```
cd 镜头设计_v3/styleframes/art/fusion/s1/inserts
BL_EXTRA=bl_lock.py BL_FRAMES=0,1,2,3,4,5,6,7 bash ../../../gpu_slot.sh blender.exe -b -t 2 -P bl_inserts.py -- lock C:/render_tmp/lock/final 0 7 64 1
```

帧号：0/1 = A 近景/中景，2/3 = B，4/5 = C，6/7 = 现版。临时帧在 `C:/render_tmp/lock/`。只新建了 `bl_lock.py`，别的文件没动。
