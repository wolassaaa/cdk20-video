# 镜头 k 换质感试样（改前 / V1 / V2）

HKBU SCIE1007 课程作业的科普视频。导演看粗剪说"有点过于低龄向"，要"换个方法来渲染"。这一份拿全片最像玩具的一段，3-02 加 3-03（片中 287.0–312.0 秒，镜头 `k`），换两种做法重渲，给导演定全片的新质感。讲的内容、镜头运动、时间点、叠字都没变，变的只是东西怎么做出来。

## 两版共用的改动

**造型**（`bl_look.py` 的 `lk_key`、`lk_lock`、`lk_slab`）

| | 改前 | 改后 |
|---|---|---|
| 钥匙厚度 | 0.24 | 0.10（约 40%） |
| 钥匙边 | 圆倒角 0.05，转角圆 0.03 | 平切倒角 0.014，转角 0.008，齿是直角 |
| 钥匙细节 | 无 | 刀身上一道 0.025 深的槽；匙柄的孔改小（半径 0.13）并偏到一侧；刀身和匙柄合成一个实体 |
| 锁厚度 | 0.62 | 0.34（约一半） |
| 锁边 | 圆倒角 0.09，孔边倒角 0.035 | 平切倒角 0.02，孔边倒角 0.008 |
| 锁孔 | 从钥匙刀身外扩 0.035 切出 | 不变，还是用钥匙自己的刀身切，所以钥匙仍然只配自己的锁 |
| 孔底 | 0.36 | 0.22（钥匙插到底后，上表面比锁面低 0.02） |

锁的不规则外形（之后要长成 CDK20）和两把锁的位置都没动。

**动作**（`lk_glide`、`lk_carried`、`lk_place`）

| | 改前 | 改后 |
|---|---|---|
| 锁和钥匙进场 | 从 40 单位高处抛下，落地回弹一次（`drop`） | 从画外贴着台面滑进来，五次方缓出，停住时速度为 0，不回弹；时长 0.5 秒，落点时间不变 |
| 钥匙放进锁孔 | 最后 0.3 秒自由落体加速撞进去，再弹两下（`carried` 的 ring） | 抬起、平移不变；最后 0.6 秒（第二把 0.4 秒）用 smooth 缓入缓出降下，到底时速度为 0 |
| 锁被撞 | 5 Hz 抖动（`jolt`） | 删掉 |
| 第二把钥匙落在错锁上 | 弹起 0.3 再落 | 慢慢放下，停在锁面上 |
| 第一把钥匙离场（312 秒后，接镜头 p） | 平方加速甩出 | smooth 缓入缓出升走 |

第一把钥匙进场改从左下方滑入：贴着台面从原来的右下方进来会穿过第一把锁。这一处在 287 秒之前，片段里看不到，但以后接全片时要用。

**叠字**：白底圆形 ✓ ✕ 徽章换成红笔手画的勾和叉（`make_look_jsx.py` 的 `PenMark`），按书写速度一笔一笔画出，略斜，笔画粗细和 Caveat 批注一致，颜色 `#E8190F`。勾在原来徽章的位置（640, 556），高 130 px；叉在（1812, 508），高 100 px。其他叠字（protein、drug、两条批注、selectivity、出处行、相纸）照 S3K 原样。

## V1 · 精工实物

思路：像一件做工精细的金属和陶瓷实物摆在骨白台面上，靠平切倒角上的细高光显出精度。

| 材质 | 参数 |
|---|---|
| 钥匙：红色阳极氧化铝 | Base `P.RED`，Metallic 0.55，Roughness 0.36，Specular 0.5，Coat 0，凹凸是沿 x 拉长的细噪声（拉丝纹，强度 0.08） |
| 锁：克莱因蓝缎面粉末喷涂 | Base `P.KLEIN`（第二把 `(0.008, 0.03, 0.62)` 不变），Roughness 0.55，Specular 0.3，Coat 0，细颗粒凹凸强度 0.03 |

灯光和台面同现版：`plate_kit` 的天光和太阳。

## V2 · 灯下标本

思路：把台面当成昏暗房间里一盏顶灯照着的标本台，只照亮主体，四周暗下去；锁和钥匙是透光的树脂，边缘透进一点光，像标本或显微镜下的样品。

| | 参数 |
|---|---|
| 环境 | 世界光乘 0.22，太阳降到 0.12 倍 |
| 顶灯 | 椭圆面光 10×6 单位，高 14，在两把锁中间上方（72.2, −2.7），功率 130 W，spread 34°；不进反射（`visible_glossy = False`），否则顶视时平面把整块灯面反射成一片白 |
| 逆光 | 低角度太阳从锁后偏右来，强度 0.9，角度 4°，不投影，只勾倒角 |
| 锁：蓝色树脂 | Base `(0, 0.03, 0.5)`（第二把 `(0.005, 0.045, 0.68)`），Roughness 0.4，次表面 0.6，半径 (0.2, 0.35, 1.0)，scale 0.05 |
| 钥匙：红色树脂 | Base `(0.75, 0.02, 0.012)`，Roughness 0.42，次表面 0.5，半径 (1.0, 0.15, 0.1)，scale 0.06 |

光池中心是骨白，画面四角暗到浅灰。

## 穿模检查

`LOOK_CLASH=2`，不渲染，全镜头 1644 帧隔一帧查，822 帧。用实体网格的 BVH 求交，再用顶点到表面的距离量最近距离。

- 穿模 0 处。
- 最近距离：第一把钥匙到第一把锁的孔底 0.003（296.80 秒插到底），第二把钥匙到第二把锁的上表面 0.003（307.87 秒放下），都是故意留的贴合间隙；第二把钥匙滑进来时离第一把锁最近 0.16（305.33 秒）。
- 所有实体最低点 z = 0.000，没有沉进台面。

两版几何和动作相同，查一版就够。

## 渲染

- 1080p，16 采样，RTX 5080，两路并行，每路一帧约 1 秒。每版渲 519 帧（片段里 72–780 和 1100–1426 号的偶数帧，其余是原镜头本来就有的停帧），两版同时跑 16:34–16:44（本机时间，香港 15:34–15:44），约 10 分钟。改滑入时长后补渲 1100–1180 号，约 1 分钟。
- 停帧接缝：780 号帧和 1100 号帧平均差 0.02 级，看不出跳。
- 叠字：Remotion 出 JPEG 序列，digiKam 的 ffmpeg 7.1.1 压 H.264。Remotion 自带的 ffmpeg 今天在本机任何目录都写不了文件（Permission denied，换 TEMP、关沙盒都一样），所以绕开它。这会影响 `cut_k.sh` 这一类老脚本，要单独查。

## 我的看法

V1 更不像玩具。玩具感主要来自"胖、圆、亮、弹"，V1 四样都去掉了，倒角上的细高光让人读出"这是精密加工的东西"，而且台面、颜色和现版完全一致，铺到全片风险最小。V2 的暗角和光池更有宣传片的气氛，但近景里树脂和 V1 的差别不大，顶视时四周发灰也让骨白台面打了折扣，叠字所在的四角变暗；要选 V2 的话，光池要按每个镜头重摆，工作量更大。

还有一点两版都没解决：顶视时锁是一整块平面，缺少细节，近看才看得出做工。

## 铺到全片要改什么

**共用函数**

| 位置 | 改法 |
|---|---|
| `fusion/code/plate_kit.py` 的 `gloss()` | 默认值改成缎面（Roughness 0.5 左右，Coat 0，Specular 0.3），或者加一个全局开关；`bl_inserts.py` 里约 40 处显式传了 0.18–0.34 和 0.6–0.7，要统一改 |
| `fusion/code/bl_shots.py` 的 `extrude()` | `bevel_resolution` 5 改 0（平切倒角），倒角宽度按厚度收小；`key()`、`lock()` 厚度换成 0.10、0.34，孔底 0.22 |
| `bl_inserts.py` 的 `drop()`、`thrown()`、`jolt()`、`carried()` | 换成 `bl_look.py` 的 `lk_glide`、`lk_carried`；各镜头里的 hop、翻跟头要逐个改 |
| `bl_inserts.py` 的 `stage()`（只有 V2） | 加 `lk_lamp()` 的顶灯和压暗，每个镜头按主体位置摆光池 |
| `entry.jsx` 的 S3K（在 `patch_s3.py` 里） | `Mark` 换成 `PenMark` |

**要重渲的镜头**

- 一定要：`k`（本段）和 `p`（锁在 312 秒长成 CDK20，起点必须和新锁的厚度、材质一致，第一把钥匙离场的曲线也变了）。
- 换材质就要：S1/S2 的 `a`、`w`、`b`、`c`、`f`、`g`、`h`；S3 的 `q`；S4 的 `i`–`i4`、`lp`、`hz`、`hk`、`w3` 以及用到钥匙和锁的镜头。

**显卡时间**（4K、16 采样、两路，按 `低龄感诊断.md` 第 2 条的估法）

- V1：本段和 `p` 约 1.5 小时；全片三维段约 13 小时（S1/S2 约 2、S3 约 4、S4 约 7）。
- V2：次表面和面光在 1080p 上没有变慢（每帧都约 1 秒），4K 按多 15% 估，约 15 小时；另加每个镜头摆光、看静帧的人工。
