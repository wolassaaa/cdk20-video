## v2 改了什么

- 蛋白生长时没接在管口：旋转轴高度不对，链条离管口约 160 px。轴改到残基 1，重渲 900 帧，最终姿态不变。
- 蛋白盖不住管子：相乘合成让管子透过蛋白。现在按画面的颜色认出物体，先擦掉物体下方的台面，再乘上去。肝的门静脉接口也一起改了。
- 肝和蛋白的渲染范围边缘有色差，最大 4 级。现在阴影和反光朝边缘羽化。
- 地图左缘和上缘把陆地切成直线。现在陆地朝这两边淡进台面。
- 台面和地图的接口有一条白线，管子也对不齐。取整改成重叠 1 像素，管子在接口处融合。
- 台面底色和画外差 1 级，已统一。
- 蛋白在 97.0 秒一下子出现，现在用 0.4 秒淡入。
- 审片字幕加宽到两行，不再压住标签。

## 怎么核对的

- 全部 8460 帧做了相邻帧差。突变只出现在设计好的地方：三下落珠、相纸落桌、审片字幕换行。
- 关键帧看过版面、遮挡和接缝。液面、蛋白生长和尾巴红蓝都对。
- 只看了抽帧和数值，没有连续播放，节奏和"像不像滑网页"要导演看片判断。

## 已知问题

1. **蛋白的底色每帧单算。** 蛋白长大后遮住上下边的取样行，基准从 242 降到 234，物体在 7 秒里慢慢亮约 3%，中途有几次 1 级的小跳，肉眼难见。下次改成固定用第 0 帧的底色（242, 240, 233）。
2. **横移没有动态模糊。** 1920 px 走 1.4 秒，峰值每帧约 40 px，有蛋白这种高反差物体时最明显。要不要加，等导演看完再定。
3. **地图只有 3 倍分辨率。** 4K 下推近到 3 倍会发软，要重渲到 6 倍。
4. 真人相纸全是占位，音乐和旁白都没有。
