## v2 改了什么

- 蛋白生长时没接在管口：旋转轴高度不对，链条离管口约 160 px。轴改到残基 1，重渲 900 帧，最终姿态不变。
- 蛋白盖不住管子：相乘合成让管子透过蛋白。现在按画面的颜色认出物体，先擦掉物体下方的台面，再乘上去。肝的门静脉接口也一起改了。
- 肝和蛋白的渲染范围边缘有色差，最大 4 级。现在阴影和反光朝边缘羽化。
- 地图左缘和上缘把陆地切成直线。现在陆地朝这两边淡进台面。
- 台面和地图的接口有一条白线，管子也对不齐。取整改成重叠 1 像素，管子在接口处融合。
- 台面底色和画外差 1 级，已统一。
- 蛋白在 97.0 秒一下子出现，现在用 0.4 秒淡入。
- 审片字幕加宽到两行，不再压住标签。

## 重现

S1 和 S2 现在是同一张台面、同一条时间线，代码都在这里。S1 是第 0–141 秒，S2 是第 141–283 秒。

```bash
cd 镜头设计_v3/styleframes/art/fusion/s1/code
bash render_all.sh 1                       # Blender：台面、地图、S2 新台面、肝、蛋白，1 是 1080p，2 是 4K，已有的帧跳过
bash render_film.sh out.mp4 1 0 141        # 输出路径、1080p 或 4K、起止秒，只出 S1
bash render_film.sh out.mp4 1 30 50        # 任意一段都能单独出，测试只花几分钟
```

底图按 30 秒一段、三段同时跑，已做完的段跳过，所以中断后再跑一遍就能接上。用时写在 `镜头设计_v3/工作记录.md`。

显卡用 OptiX。11-02 实测同一帧 4K：肝 14.4 秒对 CUDA 64 秒，蛋白 6.7 秒对 55 秒，玻璃 8.8 秒对 9.0 秒。`CYCLES_BACKEND` 环境变量可以切换。

4K 台面太大，降噪一次过会爆显存，三张全黑。现在超过约 5000 × 4400 px 的图分块渲染，`stitch.py` 拼回去。

## 11-02 新加的药物

1-04 的台面上加了两样模型，都是示意，没有厂家标记，标 `schematic`：

- Nexavar 是片剂，做成一板红色药片。换代后淡到 40%，和名字一起变灰。
- atezolizumab + bevacizumab 是静脉注射，做成两支注射瓶，克莱因蓝瓶盖。

模型只进 F 层，字改到物体下方。第 30–50 秒的 1080p 片段查过相邻帧差，没有计划外的突变。

## 改节奏：节奏表

真声音来了以后，只改 `节奏表.csv`，用 Excel 或任何文本工具都能开。

1. 听实际录音，在"实际开始"一列填每句台词真正开始的时间。写 `76`、`76.5` 或 `1:16.5` 都行。
2. 空着的行跟上一行平移同样的秒数，所以只填量过的就行。需要更细时可以加行，"原定开始"写原来的时间点，并按时间顺序排。
3. 跑 `python timeline.py`，看每段的快慢比例和总长。时间排错了会直接报错，不会出片。
4. 跑 `bash render_film.sh out.mp4 1 0 141`。

一句话里的动作按比例拉伸；镜头移动保持原来的速度，只有那一段实在太紧才一起压缩。肝和蛋白用同一批帧，放慢时帧会重复，比例离 100% 太远要看一眼。

验证：表空着时全部 8460 帧的镜头数据和 v2 完全相同。填一份测试表后，每句都落在填的时间上，抽查的字和画面和原定时刻逐像素相同，镜头移动没有变长，排错的表报错退出。这几项都是表层核对，没有用新表出过整片。

## 已知问题

1. **蛋白的底色每帧单算。** 蛋白长大后遮住上下边的取样行，基准从 242 降到 234，物体在 7 秒里慢慢亮约 3%，中途有几次 1 级的小跳，肉眼难见。下次改成固定用第 0 帧的底色（242, 240, 233）。
2. **横移没有动态模糊。** 1920 px 走 1.4 秒，峰值每帧约 40 px，有蛋白这种高反差物体时最明显。导演看 v2 时没有提，暂不加。
3. 4K 的地图已按 6 倍渲染，推近到 3 倍不会发软。
4. 真人相纸全是占位，音乐和旁白都没有。
