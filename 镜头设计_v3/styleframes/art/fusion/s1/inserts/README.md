# S1 插入镜头

HKBU SCIE1007 课程作业的科普视频。导演说 S1、S2 像 PPT，又否了只动镜头和颗粒变形两版。这一步不重做现版，只在长停顿里硬切进真 3D 特写，白底、配色和物体不变，机位压到桌面高度，一个镜头里一个东西做一件事。现行代码和 4K 成片没动。

## 这版改了什么

| 片内时间 | 时长 | 镜头 |
|---|---|---|
| 33.0–35.3 秒 | 2.3 秒 | 药片顶破铝箔，落到桌上晃几下停住，叠字 Nexavar |
| 35.3–37.9 秒 | 2.6 秒 | 两瓶药先后放下，液面晃动后静止，旧药板虚化在后面，叠字两个药名 |
| 44.4–47.4 秒 | 3.0 秒 | 贴着桌面看十个人，七个人的红色依次退到底，三个留下 |

其余时间就是现版。七人退红的先后间隔和现版相同，都是 0.22 秒。

## 结果

- 三个镜头 474 帧，1080p，64 采样，三路同时跑，用时 8 分 26 秒。
- 压片和切片 1620 帧，2 分 18 秒。
- 成片 `inserts_25_52.mp4` 9.9 MB，约 2.9 Mbps，低于 Moodle 全片约 7.5 Mbps 的上限。
- 只有计划的 5 个硬切点有大的帧差，三个镜头里没有单帧闪跳。
- 特写和现版的底色相差不到 1 级。
- 4K 实测：药瓶镜头单路 8.4 秒一帧。

## 已知问题

- 只看了抽帧和数值，没有连续播放，节奏要导演看片判断。
- 37.9–41 秒回到全景后，画面还是静止约 3 秒。
- 特写里的药板是铝箔面朝上，药瓶是立着的；全景里药板是药泡面朝上，药瓶是躺着的。
- 药片顶破铝箔、瓶子放下都是示意，标了 `schematic`，没有新的科学说法。
- 4K 只测了一帧，没有跑完整镜头。

## 重现

- `bash render_inserts.sh` 渲三个镜头，帧在 `frames/`，不提交。
- `bash cut.sh <工作文件夹>` 压片并切进现版。工作文件夹里要有 `motion_public/fusion_s1/fonts`。
- `patch_entry.py` 在 Remotion 源目录生成 `entry_cut.jsx`，`cut.sh` 跑完会把它移走，不提交。
