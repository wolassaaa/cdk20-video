# S1 台面镜头

HKBU SCIE1007 课程作业的科普视频。导演说 S1、S2 像 PPT，这里不重做现版，只在第 32–49 秒把全景换成真 3D 镜头。第一版是硬切，导演说转场还可以更有创意，所以这一版的 `inserts_25_52_v2.mp4` 不用硬切：镜头落到同一张台面上，平面上的东西站起来；镜头升回去，它们躺回全景。

全景本来就是 Blender 俯视渲染，600mm 长焦、高 160 单位的相机几乎和它逐像素重合，所以接缝处只有字在淡入淡出。现行代码的 `S1` 和 4K 成片没有换成这一版，这一版只在 `patch_entry.py` 生成的 `Cut` 合成里。

## 这版改了什么

| 片内时间 | 转场 |
|---|---|
| 32.1–33.2 秒 | 全景的药板位置空出来，药板从镜头上方落下，镜头跟着落到台面 |
| 33.2–35.3 秒 | 药片顶破铝箔，落到桌上，叠字 Nexavar |
| 35.33 秒 | 第一只药瓶贴着镜头落下盖住全屏，就在这里切到药瓶镜头，不是硬切 |
| 37.55–38.4 秒 | 镜头升回俯视，两瓶向后躺下，正好落到全景里的位置 |
| 43.35–44.4 秒 | 字淡出，镜头落下，十个人依次立起 |
| 46.95–48.5 秒 | 七个灰的先躺下，三个红的最后躺下，镜头升回全景 |

导演同一轮提的另外两件事也在这版里：

- 相纸不再压图。全片只有 0:25–0:31 压到肝，相纸改成 620×744，左列的字在相纸落下前清掉。
- `schematic` 斜线标全删，示意场景在灰色出处行开头写 `Illustration ·`。AlphaFold 的 `predicted` 和对接的 `OUR RE-DOCKING` 保留。

`~3 in 10` 在十个人的镜头里放在左上，镜头升起前淡出，回全景后在原位再出现，中间约 0.9 秒没有这行字。放回原位的话，人排升起时会扫过字。

## 结果

- 四个镜头 750 帧，1080p，64 采样，三路同时跑，15 分 6 秒，每路约 3.6 秒一帧。
- 十个人的镜头改构图后重渲 310 帧，单路 6 分 21 秒，约 1.2 秒一帧。
- 合成切片 1620 帧，2 分 21 秒。
- 成片 14.2 MB，约 4.2 Mbps，低于 Moodle 全片约 7.5 Mbps 的上限。
- 帧差：没有单帧孤立跳变。最大变化在第 35.23–35.52 秒的落瓶，均值 18.35，峰值 56.41，这一段是设计好的；另外四个转场均值 1.96–3.46，峰值 5.96–11.75。第 31 秒的帧差约 12 是全景原有的平移，第一版也有。
- 全景贴片的边缘两侧亮度差不超过 2 级，看不出接缝。

## 已知问题

- 只看了抽帧和数值，没有连续播放，节奏要导演看片判断。
- 全景的药板在 38.4–52.2 秒换成破洞铝箔面，靠贴片 `patch_top.png`。S1 现行版还是八颗粉药片，这段要等导演定了才并进去。
- 第 47 秒七个人躺下，情绪比现版重，要导演判断。
- 药片顶破铝箔、瓶子落下和倒下、人立起和躺下都是示意，没有新的科学说法，出处行写 `Illustration`。
- 4K 没跑。S1、S2 的 4K 成片还是旧相纸和旧标。

## 重现

- `bash render_inserts.sh [a b c w]` 渲镜头，帧在 `frames/`，不提交。
- `bash cut.sh <工作文件夹> [输出]` 拼接、压片并切进现版，默认输出 `inserts_25_52_v2.mp4`。
- `merge.py` 找药瓶完全盖住画面的帧做切点，并切出贴片。
- `patch_entry.py` 在 Remotion 源目录生成 `entry_cut.jsx`，`cut.sh` 跑完会把它移到工作文件夹，不提交。
