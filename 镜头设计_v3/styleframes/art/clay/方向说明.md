# clay · 黏土方向说明

这是香港浸会大学 SCIE1007 课程作业的科普视频，这份说明只讲视觉方向。

**主张：** 全片是一张工作桌，所有东西都是手捏的，严肃的癌症故事用最不严肃的材料讲。

**八段颜色：** S1 全黑加暗红的肝；S2 芥末黄墙；S3 回到全黑；S4 暗棕底、奶色软泥；S5 绿切割垫加白釉；S6 橙墙，灯到第四站门口；S7 冷蓝晨光；S8 砖红暖光收。切割垫的绿、桌面和碎屑贯穿全片，S1、S3 把绿色抽掉。

**四种证据：** 实测是烧过的硬陶，上釉，有硬高光，蓝字；AI 预测是没烧的软泥，带指纹，尾部的浅色来自真实 pLDDT；我们的对接是铅笔画在纸上，手写字加虚线框；示意是揉皱的纸条。四种的形状和质地都不同，不靠颜色。

**人怎么放：** 真人手机素材抠像，暖调，留一圈剪刀剪出的纸边，像照片剪下来立在桌子后面，桌沿挡住下半身，墙上加投影。T2 现在是占位，纸边和调色就是素材要过的处理。

**动起来：** 定格动画的手感，12 fps 抖一下；下一镜是一只手把泥捏成下一个东西，转场不用淡入淡出。指纹全片不动，只有捏的时候变。

**比现在多花：** Blender 一张 1080p 约 20–30 秒，表面变形要逐帧做，4K60 按 8 倍算。整片估计比现有流程多 40%，主要花在捏泥转场和人物抠像。

**最大风险：** 桌面戏一多会变成儿童节目，T1、T3 的黑场必须守住。其次是手机素材贴进来像贴纸，要靠光线和投影压住。

**字体：** Segoe UI Bold、Segoe Print Bold（均为 Windows 字体）。机器上没找到可直接用的 SIL OFL 字体文件，定稿要换。T1、T3 是额外加做。
