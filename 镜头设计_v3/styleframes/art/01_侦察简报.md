# 第一轮侦察简报 · 2026-10-31

这是香港浸会大学 SCIE1007 课程作业的科普视频，不是科研项目。这一轮只试画面风格：用同一个蛋白模型，快速试几十种视觉风格，一批一批筛，最后留下不超过五个给导演看。

## 导演要的感觉

要前卫，不符合常理，但大家看得懂，看完觉得"哇，这个好酷"。如果一张图看起来像普通科普片，就算失败。如果一张图很酷但看不出画的是什么，也算失败。

## 每种风格交一张图

- 主体：CDK20 蛋白，真实数据。可以放大、裁切、旋转，可以只露一部分，要让它有体量和气势。
- 大字：`CDK20`，用这种风格该有的字。
- 小标签：`AlphaFold DB v6 · predicted`，要读得清。
- 尺寸 1280×720，文件名 `scouts/<组>/<编号>_<英文名>.png`，比如 `scouts/a/a1_constructivism.png`。

## 每种风格的时间

一种风格不超过 6 分钟。这一轮只求看得出味道，不求精修。**本地时间 13:20 前全部交完**，用 `date` 看时间，到点就交，做不完的写明。

## 怎么做得快

共用素材已经渲好，放在 `镜头设计_v3/styleframes/art/_passes/`，不用重渲。

- **numpy 路线，一分钟一张，优先用：**

```python
import sys; sys.path.insert(0, r"D:/。hkbu/molecular science/镜头设计_v3/styleframes/art/_shared")
from passes import load, save
P = load(scale=0.667)   # 1280x720 的数据层
```

`key`、`rim` 是两个方向的光，`ao` 是缝隙阴影，`normal` 是法线，`depth` 是远近，`conf` 是真实置信度（低于 0.7 就是尾巴），`pos` 是空间坐标，`mask` 是蛋白的范围。等高线、体素、网点、抖动、笔触、光晕都能从这些算出来。

- **Blender 路线，要真材质时用**（液态铬、玻璃、黏土、体积雾）：看 `_shared/scene_cdk20.py` 开头的用法，同一个相机和网格。一张控制在 60 秒内，能用 EEVEE 就用，一次只跑一个，命令外面套排队脚本：

```bash
bash "D:/。hkbu/molecular science/镜头设计_v3/styleframes/art/gpu_slot.sh" "D:/software/tools/blender.exe" -b -t 4 -P 脚本.py
```

- 其他数据：`assets/alphafold/AF-Q8IZL9-F1-model_v6.pdb`（原子坐标，可以画点云、缎带、连线），`Remotion 项目/src/v3/s2plus/data/sequence.json`（346 个字母序列）。
- 这台机器没有 RDKit，不要安装新东西。字体可以用 Windows 自带或机器上已有的，这一轮只看感觉。

## 看真图

只读文字做不出味道，上一轮就栽在这里。每种风格动手前，用内置浏览器（`mcp__Claude_Browser__*`，开自己的标签页）看一两张真实作品，一两分钟就够。浏览器忙或打不开就跳过，在记录里写"没看真图"。参考图不存到本地。

## 规矩

1. 只学方法，不用任何人的标志、字体、角色、界面和素材，不要临摹某件具体作品。
2. 不闪，不做频闪。
3. 蛋白数据是真的，不要画假分子。
4. 不写新的科学说法。
5. 只在自己那一组的文件夹里写，不改别的文件，不运行 git。
