# W0 · 00:00–00:02 · three percussion hits, no voice: style frames (agent w0)

These frames lead straight into 1-01 ("Every day in Hong Kong, about four people die of liver cancer."), so each option builds over the three hits toward the image that carries "four a day" in 1-01 (see `../1-01/README.md`).
There is one frame per hit: `_hit1`, `_hit2`, `_hit3`. Alternates are `_hit3_alt` / `_hit3_branch`. The palette is black, bone, crimson-vermilion and pure blue/IKB, with no orange, yellow or green. All Blender renders use the Standard view (no AgX/Filmic).
The words "WHICH / MOLECULE / FIRST?" in the old storyboard are **not** used. Under the v2 brief, W0 is pure image on the hits. If they come back, `post.py --word` can lay them on any of these frames.
Option 3 (fog-glass) was dropped in pass 2, because 1-02's `opt1_fog-tally` covers that material. Its code stays in `_code/w0/` (`fogmask.py`, `opt3_fog_bl.py`, `fog_post.py`).

Code: `../_code/w0/`. `bl_common.py` holds the Blender helpers and `sf.py`/`post.py` handle bloom, grain, vignette, the A card and the ILLUSTRATIVE tag. Run Blender as `blender -b --factory-startup -t 4 -P optN_*.py -- --shot <shot> --samples 512 --out RAW.png`. Raw 16-bit renders stay local in scratch.
Colour check: `_code/w0/redcheck.py`. Every frame has 0 % orange pixels (G > 0.35·R **and** G > B; at most 1.6 % on the opt2 hit2 tube core). The strict G > 0.35·R rule alone still flags 2–30 % of opt5's red pixels: the thin wool, its sheen and the haze in front. Those pixels have B ≥ G, so they read as dull crimson or rose, not orange.
