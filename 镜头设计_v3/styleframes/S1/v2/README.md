# S1 视觉选项 · 第二轮（10-30 夜里）

整个第一幕，每个镜头 4–9 个方案。

- **看图**：`_gallery/` 里每个镜头一张总表。每行是一个方案，编号写成"镜头 · N"。W0 和 1-01 是同一个开头，所以放在一张表上：每行先是三下鼓点的三帧，最后一张是 1-01 的"四个人"帧。
- **回复**：直接说"W0 选 1、1-02 选 2"就行；也可以说"1-04 的 2 加 3 的最后一帧"。
- **规则**：只用红、蓝、黑、骨白，不用橙、绿、黄，也不用热成像色带。Blender 渲染全部改成 Standard 色彩变换，红色往深红偏，每张都用脚本查过有没有发橙。
- **文件位置**：
  - 每个镜头文件夹里的 README 写了每个方案参考的艺术家、用的工具、对应的台词；
  - 代码在 `_code/<组名>/`；
  - 渲染图只在本地，不进 git。
