# Orca 使用说明（给导演）

HKBU SCIE1007 课程作业的科普视频。从 11-09 起，这个项目在 Orca 里跑：总管 Claude 拆活、派活、验收，Codex 和 DS（DeepSeek Harness）当工人。这份讲怎么开、怎么看、出事怎么办，不涉及片子内容。

## 1. 开工

1. 打开 Orca（开始菜单里的 Orca，装在 `C:/Users/woola/AppData/Local/Programs/orca`，v1.4.254）。
2. **第一次先改成聊天界面（只做一次）**：设置 → **Agents** → Installed 列表里，把 Claude、Codex、DeepSeek Harness 每一行的 **Chat | CLI** 都点成 **Chat**。之后新开的总管和它派出的工人都是聊天窗口，不是命令行。已经开着的命令行标签：右键标签选 **Continue in Chat UI**（或按 `Ctrl+Shift+F11`），对话会接着搬到聊天窗口里。
3. 左边选项目 **molecular science** 的 **main**（就是 `D:/。hkbu/molecular science` 本身，不是副本）。
4. 新开一个 Claude 聊天，第一句贴：

> HKBU SCIE1007 课程作业的科普视频。你是总管 BlueLake，先读 `镜头设计_v3/orca/总管规矩.md`，照它开工。今天要推进的是：＿＿＿＿。

之后你只和总管说话。它派出去的工人会在同一个页面里各占一个窗格，点进去能看、也能直接插话。

## 2. 分工

| 谁 | 干什么 |
|---|---|
| 总管 Claude | 拆活、派活、验收、推进主线 |
| Codex | 文件和资源：磁盘、资源清单、交付体积、仓库卫生（`协作信箱/RedStone_资源管理.md`） |
| DS（DeepSeek Harness） | 4-10、5-04、S5 和杂活；讲论文生物内容的文字和画面优先给它 |

细则在 `总管规矩.md`。总管遇到改剧本、覆盖正式片、长渲染、花钱、对外发消息、审美二选一时会停下来问你。

## 3. 以前的对话

Orca 右侧栏 **Agents** 页（Agent Session History）会自动列出这台电脑上 Claude 和 Codex 的历史会话，范围选 **Project** 就只看这个项目。点一条能看内容，点 **Resume** 在 Orca 里接着聊。不用导入。

## 4. DS 要先填 key（只做一次）

DS 用的是 DeepSeek Harness 桌面版自带的命令行（`C:/Users/woola/.local/bin/dsh.cmd`、`dsh-tui.cmd` 两个启动脚本）。命令行版要 DeepSeek 的 API key，下面两种方法选一种，你自己填，别贴给 agent：

- 在终端里跑 `dsh web`，浏览器里打开它的 **Models** 页填 key；或者
- 在 Windows 的"编辑账户的环境变量"里新建 `DEEPSEEK_API_KEY`，填完重开 Orca。

填好后在终端跑 `dsh headless 只回复两个字：在呢`，回了"在呢"就通了。

## 5. 和协作信箱的关系

Orca 管派活、叫醒、看进度；协作信箱（`协作信箱/使用说明.md`）先留着管文件占用。两边并行用几天，Orca 顺手了再定要不要停掉信箱。

## 6. 11-09 试跑结果

- 第 1 轮：总管派 Codex 只读列文件，Codex 报回 4 个文件和字节数，总管用 `ls -l` 核对全对。但 Orca 自己没叫醒总管，是手动提醒的。
- 第 2 轮：改成总管派完活在后台跑 `orca orchestration check --wait` 等信（写进 `总管规矩.md` 第 2 节），派 Haiku 小工人数文件，工人回信后总管被自动叫醒、核对通过。
- DS 还没试：差 DeepSeek 的 key（第 4 节）。
- 聊天界面：用聊天模式起的 Claude 能正常跑 `orca orchestration` 命令（列任务、查当前任务都通）。在聊天界面里派工人、后台等信叫醒这一整轮还没完整试过，改成聊天界面后第一次正式派活时留意一下。
- Orca 设置里"运行 agent 时保持电脑不睡"（keepComputerAwakeWhileAgentsRun）现在是关的；要通宵跑，在 Orca 设置里打开它，或者电脑设成不睡眠。

## 7. 出事怎么办

- 总管卡住不动：在它的窗格里直接打字问它；或者 Esc 打断再说。
- 工人跑偏：点进工人的窗格打断它，或者让总管 `worker-stop`。
- Orca 关了：工人会停，重开 Orca 后让总管 `orca orchestration run-list` 接着做。
- 全程权限是全开的（Claude 跳过确认，Codex 不设沙箱），兜底靠规矩：只挪不删、显卡最多两个 Blender、不用 `git add -A`。
