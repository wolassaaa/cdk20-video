# 视线引导（替代红色料珠）

HKBU SCIE1007 课程作业的科普视频。这份文档定全片新的"视线引导"：观众下一眼该看哪里，由什么告诉他。写于 2026-11-20（韩国时间），按导演 11-20 的意见（`导演意见_1120.md` 第 1 条）重新设计，给施工的人照做。本文只定做法和参数，不改任何页面代码；kit.jsx 和 Blender 脚本另派施工。

导演原话："当然要有引导，就是这个交互不行，得换，得根据新的设计思路来搞。"之前还说过红点"看多了晃眼睛"。

## 一、结论

**主方案：焦点点名。** 说到哪个零件，镜头的焦点就先一步落到它身上：它从虚变实，同时一盏只照它的轮廓光把它的边缘提亮一点点；别的东西保持在景深外。画面上不多出任何东西。

**辅助一：浇口预颤，带一声轻"嗒"。** 被点名的零件在词开口前 4–8 帧，在浇口上绷一下（往外拉一点再回来），料杆跟着轻颤，同一时刻一声很轻的塑料"嗒"。零件本来就要被"拔"出来时，这一下就是它的预备动作，不另加。

**辅助二：料杆走料，只用于远距离换场。** 下一个要讲的零件不在画面里、或者离当前焦点超过画面宽度的 35% 时，一个鼓包沿料杆从当前位置走到那个零件的浇口，焦点和镜头跟着鼓包走；鼓包到浇口就被零件"吃"进去，消失。其余时候不用。

**不用的手段：** 说明书式的步骤编号（会在画面上加二维字，和"二维只留标签、出处、批注、字幕"冲突，也会和 E3 的标签数抢名额；第 6 章记分板的行号是内容本身，不算引导）；打光以外的发光材质（零件一自发光就像灯泡，塑料感没了）；单独的指示物（箭头、圈、点，就是红点的老问题）。

### 为什么比红点好

| | 红色料珠（旧） | 焦点点名 + 预颤 + 走料（新） |
|---|---|---|
| 画面上多出的东西 | 一颗一直在场的高饱和小点 | 没有。引导就是零件自己、焦点和光 |
| 不需要引导时 | 小点还在，停着也在抢眼 | 什么都不发生，画面安静 |
| 眼睛的负担 | 小而亮的运动物体会持续触发眼跳和追视，17 分钟下来就累 | 眼睛本能去看清楚、稍亮的地方，不用"追"任何东西 |
| 和世界的关系 | 贴在纸面上的标记，和三维大板无关 | 景深、灯、浇口、料杆都是大板本来就有的东西 |
| 和念词的关系 | 跳站，常常和零件自己的动作打架（两样东西同时动） | 引导就是动作的前奏，主动作仍落在词上 |

## 二、三个手段的规则

时间全部从事件表来（`映射/events/<段>.json` → `resolve.py` → `映射/keys/<段>.json`）。下文 `f_land` 是被点名的词开口那一帧（事件的落点），帧数都是 60 fps。

### 2.1 主方案：焦点点名

**什么时候用：** 一个词第一次叫出一个零件（或零件上的一个部位：凹槽、摆臂、站牌），而且这个东西现在不在焦点上。

**怎么走：**

1. **起拉** `g_start`：焦点开始从当前目标移向新目标。
2. **到位** `g_on`：新目标完全清楚。`g_on` 在词开口前 4–12 帧（默认 8 帧）。
3. **起拉到到位** 12–24 帧（默认 18 帧），缓入缓出，不过冲、不来回找焦。
4. **轮廓光** 和焦点同一条曲线：`g_start` 起亮，`f_land` 到峰值，最多保持到这个事件的 `f_end`（且不超过 `f_land` 后 120 帧），然后用 24–36 帧退回 0。
5. **焦点留下：** 轮廓光退掉以后焦点不退，留在这个零件上，直到下一次点名。所以画面永远有一个清楚的主体，不会整片虚掉。
6. **镜头跟焦点，不领焦点：** 如果这一步还要移镜头（`camera_to`），镜头起动不早于 `g_start` 后 6 帧。观众先看到"那里变清楚了"，镜头再过去。

**不点名的情况（这些时候什么都不加）：**

- 同一个零件刚被点过，下一个词还是说它（例如 3-01 的 "lock" 紧接 "picture"）。
- 标签、出处行、字幕出现（`appear`）：字不需要引导。
- 剧本里的空拍、出镜段的人在说一句不涉及零件的话。
- 两次点名的 `g_on` 不足 36 帧：后一个并进前一个，焦点直接放在两者之间能同时看清的位置，只点一次。

### 2.2 辅助一：浇口预颤 + "嗒"

**什么时候用：** 每次焦点点名都带一次；零件这一下要做 `eject`（拔）或 `snap`（拼）时，它自己的预备动作（精致度标准 D1）就是预颤，不另加。

| 项 | 值 |
|---|---|
| 起止 | `f_land − 6` 起，`f_land` 收回（4–8 帧可调） |
| 动作 | 沿浇口方向向外绷一下再回来：位移 0.3–0.6 mm（画面上不超过 6 像素），转动不超过 2° |
| 浇口 | 同时被拉细到 85% 粗，回弹 |
| 料杆 | 两次以内的衰减颤动，12 帧内停，画面上不超过 3 像素 |
| 声音 | 一声轻的塑料"嗒"，在 `f_land − 3` 到 `f_land − 6`（50–100 ms，正好是 03 文档"音效放在词前 50–100 ms"的规定），比零件弹下的"咔"轻 6 dB |

### 2.3 辅助二：料杆走料

**什么时候用：** 只在两种情况：

- 新目标在画面外。
- 新目标离当前焦点的距离超过画面宽度的 35%。

每句话最多一次。

| 项 | 值 |
|---|---|
| 鼓包 | 沿用 2-03 已认可的鼓包（`inserts/bl_s203_board.py` 的 `make_pulse` / `put`）：包住料杆的纺锤，大小跟料杆粗细走 |
| 颜色 | 料杆本色提亮，最多 +0.3 EV；**不用红色**（红色留给内容：凹槽红圈、描红站牌、红尾巴） |
| 起点 | 当前焦点所在零件的浇口，或上一段带过来的那颗鼓包 |
| 到达 | 到目标浇口前，比 `f_land` 早 0–8 帧 |
| 速度 | 画面上不超过每秒 0.6 个画面宽；走料时长 24–90 帧，太远就让镜头一起滑，不让鼓包飞 |
| 焦点 | 走料期间焦点挂在鼓包上；到浇口后转成焦点点名的"到位" |
| 收尾 | 到浇口后 6 帧内被零件吸进去，消失。**任何时候都不停在画面上等** |

走料就是 01 文档第四节"出来"第 1 种（东西从浇口钻出去、顺着料杆走、镜头跟着到下一格）和 1-09、2-08 那条主料杆的同一件事，所以它同时是转场的载体。

### 2.4 三个手段的分工

| 场合 | 焦点点名 | 浇口预颤 | 料杆走料 |
|---|---|---|---|
| 画外板面段，目标在画内近处 | 有 | 有 | 无 |
| 画外板面段，目标在远处或画外 | 有（跟着鼓包） | 有 | 有 |
| 钻取段（零件内部） | 有（微距，景深最浅） | 换成机构的预备动作（摆臂抬一点、齿轮停半拍） | 无（内部没有料杆；有内容意义的东西在走，比如 ATP 料珠，焦点跟它，它不是引导） |
| 出镜段 | 只作用在零件上，不碰人 | 有 | 无 |
| W 段（音乐） | 跟拍子走，不跟词；每小节最多一次 | 跟重拍 | 允许（W0、W1 的那道光就是走料，见 03 文档第七节） |

## 三、出镜段的特殊规定

出镜段画面里最强的引导永远是人的脸和手，我们不跟它抢。

- 人是手机实拍，焦点固定，**不给人加光、不虚化人、不在人身上做任何引导**。
- 零件在等待时略虚：画面上弥散圆 2–4 像素（1080p），轮廓光为 0。被点名时变实（≤ 1 像素），轮廓光最多 +0.2 EV（比画外段低一档，因为旁边有人脸做对比）。
- 人的手势就是引导：精致度标准 F3 要求每组出镜段至少一处手伸到零件前面，那一处手的动作本身负责带眼睛，那一拍零件只预颤，不再加光。
- 零件的主光和人的主光同侧（F4），轮廓光放在零件远离人的一侧，不在人和零件之间造出一条亮缝。

## 四、二维页（过渡期，Remotion）

01 文档定了二维说明书页全部改成三维；改完之前，粗剪 v10 里还会有二维页。过渡期二维页也按同一个思路换掉红点：**纸面上的景深**。

现状：`kit.jsx` 里 `Bead` 已经返回 null（`BeadOld` 留着备查），`beadAt` 还在。以下新组件加进 `镜头设计_v2/tests/T4_remotion/src/v3/manual/kit.jsx`，旧的不删。本文只给接口和行为，施工另派。

### 4.1 `guidePlan(K, opts)`：从事件表算出引导表

```js
// K = keys/<段>.json；返回按时间排好的引导列表
guidePlan(K, {gOn = 8, pull = 18, minGap = 36, hold = 120, relax = 30} = {})
// → [{id, target, kind, gs, gon, land, gend, goff}]
//   kind: "focus" | "runner"；target: 页面图层 id
```

- 有 `K.events[i].guide`（见第六节事件表扩展）时按它来；没有时按默认规则：`grow`、`eject`、`snap`、`move` 到一个新对象 → `focus`；`appear` 和 `camera_to` → 不引导。
- `gon = land − gOn`，`gs = gon − pull`，`gend = min(f_end, land + hold)`，`goff = gend + relax`。
- 相邻两次 `gon` 不足 `minGap`：合并成一次，target 写成数组。
- 同一个 target 连续两次：只保留第一次。

### 4.2 `<Lens>` 和 `<Layer>`：纸面景深

```jsx
<Lens plan={plan} f={f} blur={2.2} dim={0.82} desat={0.75} relax={24}>
  <Layer id="cdk20"> <Part name="cdk20" ... /> </Layer>
  <Layer id="gear">  <Part name="gear" ... /> </Layer>
  <Layer id="inset"> ... </Layer>
  <Layer exempt> <Label .../> <Title .../> </Layer>   {/* 字永远不虚 */}
</Lens>
```

行为：

- 引导窗口（`gs` 到 `goff`）里，被点名的 Layer 保持原样；其他 Layer 加 `filter: blur(b) saturate(s)` 和 `opacity: o`，在 `gs → gon` 之间从 0 渐到 `blur=2.2px`、`desat=0.75`、`dim=0.82`，在 `gend → goff` 之间退回。
- 引导窗口以外，整页全清楚（二维页上没有"景深"可以一直保留，长时间虚着会妨碍读标签）。
- `exempt` 的 Layer 永远不虚：标题、标签、手写批注、出处行、`Legend`。字幕在全片统一烧，不进页面。
- 被点名的 Layer 加一点"轮廓光"：`filter: drop-shadow(0 0 6px rgba(255,250,235,0.9))`，强度跟 3D 的轮廓光同一条曲线，峰值时整个元素平均亮度提升不超过 8%（纸是浅色，提亮空间小，主要靠别的变虚）。
- 用 React context 传当前帧的权重，每个 Layer 自己读。同一页同时被虚化的 Layer 不超过 6 个（headless Chrome 的模糊开销）。

### 4.3 `nudge(f, land, opts)`：浇口预颤

```js
nudge(f, land, {pre = 6, amp = 4, rot = 1.2, dir = [0, 1]}) // → CSS transform 字符串
```

- `land − pre` 到 `land`：沿 `dir`（指向浇口，`Part` 的 `gate` 参数算得出）先拉出 `amp` 像素、转 `rot` 度，再回到 0；缓入缓出，3 帧出去 3 帧回来。
- 用在 `Part` 外面套的 div 上，不改 `Part` 自己的生长动画。
- 零件这一拍本来就在长出来（`Part` 的 `at` 在这附近）时不用，生长本身就是动作。

### 4.4 `<RunnerPulse>`：沿已有的线走料

```jsx
<RunnerPulse d={path} a={gs} b={land - 4} f={f} sw={4} color={INK} len={0.08} />
```

- 只能沿**页面上已经画好的线**走（`Arrow` 的路径、放大圈的引线、`Legend` 的横线）。页面上没有线时不用，改用 `Lens` 就够。
- 画一段比原线稍粗（`sw + 2`）、颜色是原线色和纸色七三开的亮段，长度为路径长的 8%，用 `strokeDasharray` / `strokeDashoffset` 从 `a` 走到 `b`；`b` 之后 6 帧缩成 0 消失。
- 不画圆点，不用红色，走完不停留。

### 4.5 `Bead` 怎么处理

`Bead` 继续返回 null，页面里已有的 `<Bead K=... f=.../>` 调用可以先不删，换页施工时改成 `<Lens>` 包图层。`beadAt` 不再被新代码使用。

## 五、三维（Blender）

新写一个小模块 `镜头设计_v3/inserts/bl_guide.py`（施工另派），各段的场景脚本在 `schedule() → build() → check()` 的 `build()` 末尾调用一次。读 `keys/<段>.json` 的事件帧，按第二节规则生成下面四样东西。

### 5.1 焦点：逐帧烘焙对焦距离

照 2-03 已经在用的做法（`bl_s203_board.py` 里按权重混合目标位置、逐帧写 `dof.focus_distance`），抽成通用函数：

```python
guide_focus(cam, plan, targets, nf)
# plan: guidePlan 同样的列表；targets: {"cdk20": obj 或 (obj, 局部偏移mm)}
# 每帧：p = 各目标世界坐标按权重混合（权重在 gs→gon 之间用 smoothstep 从旧目标移到新目标）
#       cam.data.dof.focus_distance = (p - cam.location)·(相机朝向)，逐帧 keyframe
```

- 目标会动（零件在飞、ATP 在滚）时，每帧取它当前的位置，焦点自然跟住。
- 走料期间目标是鼓包物体本身。
- 光圈：从 2-03 的 `FSTOP = 16` 起调。用一帧试渲量：清楚主体的弥散圆不超过 1 像素，背景板面 6–14 像素（1080p），前景料杆虚到认得出形状。钻取段的微距景深最浅，出镜段零件最深（零件整个要清楚）。量好写进各段脚本的常量，不在帧间改光圈。
- 光圈叶片 `aperture_blades = 0`（圆形光斑，干净，不出六边形高光）。

### 5.2 轮廓光：只照被点名的那一件

```python
guide_rim(target_objs, plan_items, key_light, peak_ev=0.25)
# 每个被点名的目标一盏面光 GUIDE_rim_<id>
```

| 项 | 值 |
|---|---|
| 灯 | 面光（Area），大小约为目标包围盒的 1.2 倍，柔 |
| 位置 | 相对相机 120°–150°（侧后方），给边缘一条亮线，不给正面打亮 |
| 朝向 | Track To 目标 |
| 只照它 | Cycles 灯光链接（Light Linking）：`light.light_linking.receiver_collection` 设成只装这个目标的集合 `GUIDE_lit_<id>`。这样别的零件、台面、背景都不变亮，全帧平均亮度几乎不动 |
| 颜色 | 和主光同色温（暖白），不加彩色 |
| 强度 | 关键帧：`gs` 为 0 → `f_land` 峰值 → 保持到 `gend` → `goff` 回 0。峰值先按主光功率的 15% 放，试渲量被照零件边缘区域亮度，调到 +0.2–0.3 EV（出镜段 +0.15–0.2 EV） |

不碰场景曝光、不碰世界光、不给零件加发光材质做引导。内容本身就是"亮"的事件（3-04 "pocket" 红圈亮、2-08 站牌描红、记分板翻牌）照 01 文档做，那是内容，不算引导，也不受本节的亮度上限约束，但仍受全帧亮度波动的总限制（第七节 V6）。

### 5.3 浇口预颤

```python
guide_tick(part, gate, runner, f_land, pre=6, amp_mm=0.45, rot_deg=1.5, dir=None)
```

- 动作写在 **delta 变换**（`delta_location`、`delta_rotation_euler`）上，不和零件自己的主动画抢通道。
- `dir` 默认取浇口指向零件的方向；绷出去 3 帧，回来 3 帧。
- 浇口物体沿长轴缩放到 0.85 再回 1.0；料杆用 delta 旋转做两次衰减颤动（0.3°，12 帧内停）。
- 零件这一拍有自己的 `eject` / `snap` 时不调用：D1 的预备已经是预颤。
- 事件帧另写一份 `g_tick = f_land − 4` 进 keys，混音脚本照这一帧放"嗒"。

### 5.4 料杆走料

```python
guide_runner(path, f_from, f_to, target_gate)
```

- 直接复用 2-03 的鼓包（`make_pulse`、`put`、路径 `pa.at(u)`），把"从哪走到哪"改成从参数来。
- 鼓包材质 = 料杆材质，Principled 的 Base Color 提亮（不超过 +0.3 EV 对应的倍数 1.23），不加发光。
- 到浇口后 6 帧内缩成 0（2-03 已有"喂料时瘪一点"的做法）。

## 六、事件表加一个可选字段

```json
{"id": "cdk", "obj": "cdk20", "verb": "move", "at": {"word": "CDK20"}, "lead": 10,
 "guide": {"kind": "focus", "target": "cdk20", "g_on": 8, "pull": 18}}
{"id": "to_target", "obj": "station_target", "verb": "flow", "at": {"word": "lock"},
 "guide": {"kind": "runner", "from": "road_start"}}
{"id": "lbl", "obj": "label_enzyme", "verb": "appear", "at": {"word": "enzyme"},
 "guide": {"kind": "none"}}
```

`resolve.py` 照写进 keys：`g_start`、`g_on`、`g_end`、`g_off`、`g_tick`（片内帧另加 `G_*`）。`validate_events.py` 加第七节能自动查的几条。这两处改动随 kit.jsx 一起派施工。

审片时逐条打勾，不过的就是"必改"。"脚本"指 `check_guides.py`（施工时写，读 keys 和成片）；"抽帧"指在 `g_on`、`f_land`、`goff` 三帧各截一张。

| # | 条目 | 阈值 | 怎么查 |
|---|---|---|---|
