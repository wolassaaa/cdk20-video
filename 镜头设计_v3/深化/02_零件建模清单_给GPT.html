一、全体模型共用的规矩

1.1 单位、坐标、格子

照 kit_README.md：

  • 函数里写毫米，建模时乘 MM（0.001）。
  • 零件原点在格子中心，板面是 XY，Z 向上。
  • 普通零件不超出 ±26 × ±16 mm（一格）。超出的模型下面单独写了尺寸（比如套件盒）。
  • 高度（Z）不超过 +22 mm，除非下面另写。

1.2 文件和函数写法

# kit_parts_deep.py
from kit_parts_hd import *          # 继承 Part、Kit、MM、所有旧零件和工具函数
import kit_parts as _base

def h01_cdk20_lockworks(K, lod="hero"):
    P = Part(K, "h01_cdk20_lockworks", "blue")
    ...
    return P.done()                 # 返回零件根（空物体），和旧函数一样
  • 每个新函数签名 hNN_名字(K, **选项)，返回零件根。
  • 用 Part 现有的造型方法（slab box disc ring cyl ball torus tube lathe text gate）；不够用再自己写，写成 Part 外的小函数。
  • 浇口照旧用 P.gate(x, y, 方向, z) 登记，零件根上的 gates 属性要有。
  • 要能用 KP.make_cell(K, part, x, y) 挂到板上一格。

1.3 能动的件：命名和装配（动画脚本按这个抓）

每个能动的件这样装：

  1. 建一个空物体当转轴/滑轨，名字 {函数名}__{角色名}，比如 h01_cdk20_lockworks__arm。
  2. 空物体的原点放在真实的铰链点或滑轨起点，本地轴对齐运动方向（转动绕本地 X，滑动沿本地 Z，下面每件会写明）。
  3. 这个件的网格都是它的子物体。
  4. 空物体上写自定义属性 role（角色名，字符串）。
  5. 零件根上写自定义属性 rig，一个 JSON 字符串：
{"arm": {"type": "rot", "axis": "X", "min": -32, "max": 0, "rest": 0, "unit": "deg"},
 "bead": {"type": "loc", "axis": "Z", "min": -12, "max": 0, "rest": -12, "unit": "mm"}}
  1. 静止姿态时所有空物体的本地变换为零（rest 就是 0 的那个位置；rest 不为 0 的件，在建模时就把它摆在 0 位置，rest 只是告诉动画脚本开场放在哪）。

在 kit_parts_deep.py 里加三个公共函数（所有模型共用）：

函数 作用
rig(root) -> dict 返回 {角色名: 空物体}，按 role 属性找，不按名字找（名字可能被 Blender 加 .001）
pose(root, role, value) 按 rig 里的类型和轴设置值，超出 min/max 时截断并打印警告
rest(root) 所有角色回到 rest

同一个零件里一组同类件（比如五根弹子销）用 pin_0、pin_1 … 编号，从 0 起。

1.4 打开零件（钻进去用）

要钻的零件都有一个角色 shell：前壳沿分件线绕铰链翻开（type rot，0 = 合上，110° = 全开）。

  • 外壳要有真实壁厚 1.2 mm（实心体挖空，不是单面）。切开的断面要封口，断面和外壳同一种材质。
  • 合上时，内部机构完全在壳里，不露出（凹槽开口除外）。
  • 分件线在模型上看得到：两半之间留 0.15 mm 缝。

1.5 材质

只用 Kit 里已有的：red blue green white black gold clear0 clear frost yellow cellpink tail liquid nuc_red nuc_grey blue_hi gold_satin ink inkw inkg organ organ_s organ_m dishpink liq_blue land。

  • 实色件粗糙度保持 Kit 里的值（≤ 0.16），不许哑光。
  • 刻字用 P.text（Instrument Serif），浅色件上用 K.ink，深色件上用 K.inkw。
  • 片中出现的字一律英文，只写下面规定的字。

1.6 细节密度（导演 11-19："不够精致，细节不行"）

每个模型都要做到：

  • 所有外露边倒角 0.2–0.8 mm。
  • 至少一条分件线或接缝。
  • 近景下每个面都有东西可看：任何一个在近景镜头里会占画面 10% 以上的面，至少有一处细节：刻字、螺丝头、肋条、滚花、顶针印（Ø0.8 mm 浅圆坑）、浇口残痕、加强筋、刻度线。
  • 最小细节尺寸 0.3 mm（再小在 1080p 近景里也看不见）。
  • 三角面数：hero 版每个模型不超过 30 万；mini 版不超过 3 万。

四、逐个模型

h01 · CDK20 盖章机 h01_cdk20_lockworks(K, lod="hero")

用在： 3-04、5-04、5-05、5-06、5-09、W4、8-03；lod="mini" 用在 5-04/5-08 的十台小机器、h05 细胞工坊、h08 Kd 秤。

它在片子里讲什么： CDK20 是一台盖章机。表面一个红圈凹槽（口袋）；料珠落进去它就盖章（干活）；钥匙插进去占住位置；钥匙转到底会拨下一根闩把摆臂卡死（机器停工）。

外形（hero）：

  • 外壳 = cdk20_body(P, K.blue, size=36.0, peg=True) 那个外形（XY 最大边 36 mm，背面定位销）。
  • 凹槽：在 mouth 方向和外壳表面的交点处，沿 mouth 轴挖一个 Ø5.0 mm、深 6.0 mm 的圆孔。孔口外一圈红环：K.red 圆环，环中心半径 3.2 mm，管半径 0.35 mm，贴在表面上（法线对齐 mouth）。
  • 标签凸台：外壳底部附近一块 6 × 2 mm、高 0.4 mm 的小凸台，刻 CDK20（字高 1.2 mm，K.inkw）。
  • 顶针印：外壳背面 3 个 Ø0.8 mm、深 0.1 mm 的浅圆坑。

分件线和打开：

  • 分件面：过外壳中心、法线垂直于 mouth 轴且水平的平面（即把零件分成"前半"和"后半"，凹槽开口在前半上）。
  • shell：前半壳，绕分件线上沿的铰链（一条平行于分件面、经过外壳最高点下方 1.5 mm 处的直线）翻开，0°–110°。
  • 壁厚 1.2 mm，断面封口，同材质 K.blue。两半之间 0.15 mm 缝。

内部（全部写在"锁坐标系"里）： 原点 = 料珠座中心；+W 沿 mouth 轴朝外；+U 朝板面上方（与 W 垂直，尽量接近世界 +Z）；+V = U × W。
