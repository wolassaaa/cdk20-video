# 交接：Codex 整理"终版重算清单"（只读、只写清单，不渲染）

HKBU SCIE1007 课程作业的科普视频。这一步：为交片前的"整片重算"做准备。内容定稿后，我们不改任何画面内容，只把画质参数调高，让电脑把全片重新算一遍：三维提高采样或出 4K，出镜段用 4K 原素材，然后整批显卡降噪，4K 缩回 1080p，两遍编码到 ≤1 GB。这次只列清单。

## 要做

以 rc08 的拼装清单为准（`镜头设计_v3/粗剪/v10/build_v10.py` 以及同目录的 manifest/sources/joints json），对整片每一段列一行，写进 `镜头设计_v3/深化/终版重算清单_1124.md`：

| 列 | 内容 |
|---|---|
| 段号 | 如 1-01、W2、4-07 |
| 类型 | 三维钻取 / 出镜三维 / B 页（Remotion + Blender 底图）/ 素材 / 其他 |
| 成片 | 拼装实际读的文件路径 |
| 生成链 | 从源到成片的每一步命令或脚本（Blender 配方 → 合成 → 编码；Remotion 合成名 → 渲染；出镜 shot_oncam.py 段号 → comp_gpu.py…），写到能照抄执行 |
| 当前画质 | 分辨率、采样数、降噪器、编码参数（从代码里读出实际值，写出文件和行号） |
| 画质旋钮 | 改采样 / 改分辨率要动哪个文件哪一行或哪个环境变量；没有旋钮的写"需加参数" |
| 帧数 | 现片帧数 |
| 4K 估时 | 按 4K、64 采样估显卡时间（已知：4K 16 采样约 3.9 s/帧；按采样线性估，再写一个 32 采样的数） |
| 风险 | 重算后帧数、卡拍、接点会不会变；有没有随机种子、模拟缓存、逐帧烘焙文件需要固定 |

最后给汇总：
- 三维总帧数、各采样下显卡总时长（单路，和 3 路并行）。
- B 页总帧数和 4K 渲染估时。
- 出镜段 4K 素材是否都在、在哪。
- 需要加参数才能出 4K 的脚本列表。
