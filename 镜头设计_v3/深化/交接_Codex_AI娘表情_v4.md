## 0. 硬规则

1. **一比一照参考图**（img2img / 参考图编辑），不许重新设计、不许 Q 版化、不许改发型、发色、服装、配饰、瞳色、角、耳、尾巴。导演已经否决过两批"凭文字想象"的图。
2. 生图一律用**高**质量档，一张一张认真出，每张图都把下面写的全部要求带进提示词。
3. 同一角色的所有全身图：**画布尺寸、人物大小、站位、脚底位置完全一致**，只换表情和手部动作，这样视频里换帧不会跳。胸像图同理。
4. 透明背景 PNG（去背干净，发丝边缘不留白边、不留灰边）。
5. 大文件全部写 `G:/cdk20/work/mascots/codex/v4/`，不要写 C 盘和 D 盘（导演硬要求：C、D 是系统盘，写多了电脑卡）。
6. 不要提交 git，不要删除任何已有文件。

## 3. 放大到高分辨率

导演要求分辨率高一点。生成后用 GPU 动漫放大模型放大 2 倍：

- 首选 `realesrgan-ncnn-vulkan`，模型 `realesrgan-x4plus-anime`，`-s 2`。从官方 GitHub release 下载，放在 `G:/cdk20/work/tools/realesrgan/`。
- 放大后全身图长边不少于 3000 px，胸像长边不少于 2400 px。
- 放大后重新检查透明通道：边缘不能出现白边或灰边。必要时先放大 RGB，再单独放大 alpha 并合回去。
- 原图放 `v4/<角色>/raw/`，放大图放 `v4/<角色>/`。

## 4. 自检（逐条写进 `v4/README.md`）

1. 每个角色拼一张对照图 `v4/<角色>/compare_full.png` 和 `compare_bust.png`：参考图放第一格，后面是全部表情，标出文件名。
2. 逐张核对第 1 节表格里的外形要点，有一处不对就重出那一张。
3. 全身图叠在一起检查：人物轮廓、脚底位置的偏差不超过画布高度的 1%。
4. 透明边：把每张图叠在纯黑底和纯白底上各看一次，不能有光边。
5. 表情之间要一眼就能分清；如果"smug"和"neutral"看起来差不多，就重出。
6. 把总对照图 `v4/compare_all.png` 拼出来（三个角色 × 全部表情的缩略图）。
