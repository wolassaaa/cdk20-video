## 一、放在哪

放在 S7（下一步）和 S8（答案）之间，即 16:02 之后、S8 开头 8-01 之前，约 51 秒。理由：S7 刚说完"我们建议的三件事"，插段接着回答"这个领域现在到哪了"，再回到 S8 的结论；插段末句 "Experiments still decide!" 正好和 8-04 的 "Experiments still decide." 呼应。全片总长约 17:43 加 51 秒，仍在 20 分钟内。

## 六、做法

**角色（SVG）**：`mascots/Character.jsx`。每个角色分层：后饰（翅膀/尾巴）、后发、身体、脖子、脸、眼睛（可眨、wink 为弧线加星星闪光）、眉毛、腮红、嘴（按音量开合，含舌头）、前发、饰品。动作：眨眼（各角色间隔不同）、wink、说话口型、呼吸、头发摇摆、呆毛和尾巴摆动、说话时点头。出场弹跳在 three.js 里用 spring。

**three.js 舞台**：`mascots/Stage.jsx`，用已装的 three 0.170、@react-three/fiber、@remotion/three。
- 角色是平面卡片：每帧把 SVG 字符串转成 canvas 纹理（640x896）贴到平面上；三张卡片在不同深度，轻微内扣。
- 背景：渐变背板；16 组缓慢漂浮的分子球棍小模型（亮面材质，用 MeshStandardMaterial 加两盏灯）；140 个柔光粒子（加色混合点精灵）；摄像机整段缓慢推近（10.8 到 9.9）并带轻微左右摆动，产生视差。
- 数据牌：three.js 里的立体牌子（带厚度的盒子加 canvas 文字纹理，Instrument Serif），每换一条事实就翻转弹入一次；牌上印出处。
- **可替换**：角色卡片的贴图来源是一个开关。`Stage` 的 chars 项传 `pngDir` 就改用 PNG 帧序列（`public/mascots/png/<角色>/0001.png` 起），SVG 与 Codex 出的帧可以互换，接口不变。
- GPU：渲染用 `--gl=angle`，日志里确认 WebGL 渲染器是 `ANGLE (NVIDIA, NVIDIA GeForce RTX 5080 … Direct3D11)`。`--concurrency=2`。
- 耗时：3048 帧（50.8 秒 60fps）用 3 分 40 秒，约 0.072 秒/帧（两个进程并行的墙钟时间，单帧约 0.14 秒）。wink 小片 120 帧约 8 秒加启动。

**渲染与编码的小坑**：Remotion 直接出 mp4 时在本机 Temp 下写临时文件被拒（Permission denied），所以改成输出 JPEG 序列到 `G:/cdk20/work/mascots/frames/`，再用 Remotion 自带的 ffmpeg（`node_modules/@remotion/compositor-win32-x64-msvc/ffmpeg.exe`，带 h264_nvenc）编码。任务里写的 `D:/software/TouchDesigner/bin/ffmpeg.exe` 没有 nvenc 编码器，只用它做了解码。

复现命令（在 `镜头设计_v2/tests/T4_remotion` 下）：
```
python src/v3/mascots/gen_voice.py
npx remotion render src/v3/mascots/entry.jsx MascotShow G:/cdk20/work/mascots/frames/show --sequence --image-format=jpeg --jpeg-quality=95 --gl=angle --concurrency=2 --public-dir=<一个小空目录>
```
`--public-dir` 指到小目录，是因为项目 public 有 450 MB，每次渲染都会整个复制。
