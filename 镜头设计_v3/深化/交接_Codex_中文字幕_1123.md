# 交接：Codex 中文字幕翻译（简体、繁体）

HKBU SCIE1007 课程作业的科普视频。这一步：把已经定稿的英文字幕翻成简体中文和繁体中文，给最后烧"简中加英文""繁中加英文"两个双语版本用。只做文字数据，不烧画面，不渲视频。

工程在 D:/。hkbu/molecular science，相对路径都相对它。

## 读

- `镜头设计_v3/字幕/subs_en.json`：正片 414 块。
- `镜头设计_v3/字幕/subs_tag_en.json`：片尾彩蛋 32 句。
- `镜头设计_v3/深化/19_声音字幕片尾与整片收口.md` 第三节和第十一节：字幕规格、四个版本。
- 稿子 `镜头设计_v3/script/script_v3.3.md`，和中文对照稿 `镜头设计_v3/script/` 下的 `script_v3_zh.md`（有的话）。术语照中文稿的译法。

## 要做

1. **简体**：`镜头设计_v3/字幕/subs_zh_hans.json`、`subs_tag_zh_hans.json`。
   - 和英文逐块一一对应：同样的 id，同样的时间，只多一个 text_zh。
   - 每块中文不超过 22 个字，超了就压缩说法，不拆块。
   - 意思准确，口语自然，像正经纪录片字幕，不要翻译腔。
2. **术语**照这张表，表里没有的照中文稿；中文稿里也没有的，专业名词保留英文：
   - CDK20 不译；
   - 候选分子 048 写作"048"，全称照稿子；
   - target 译"靶点"，binding 译"结合"，docking 译"对接"，selectivity 译"选择性"，IC50 和 Kd 不译；
   - AlphaFold、Chemistry42、PandaOmics、Insilico Medicine 不译；
   - liver cancer / HCC 译"肝癌"。
3. **繁体**：`subs_zh_hant.json`、`subs_tag_zh_hant.json`。
   - 用 OpenCC 的 s2twp 或 s2hk 从简体转出来。课程在香港，用 s2hk。
   - 转完逐块再核一遍，看有没有转错的字和香港不常用的说法，比如"视频"应作"影片"，"质量"按语境作"品质"，等等。改了哪些列进说明。
4. 彩蛋的台词是角色对白，语气要轻快、像动画字幕。
5. **机检**（写 `镜头设计_v3/字幕/check_zh.py`）：
   - 块数和 id 跟英文完全一致；
   - 每块 ≤ 22 字；
   - 没有空块；
   - 繁体里没有残留的简体字（用 OpenCC 反查）。
6. **说明**：`导演检查_20261123/26_字幕_中文说明.html`，中文。先说结论，再列：
   - 术语表；
   - 繁体人工改过的地方；
   - 拿不准、要人看一眼的块（不超过 20 条）。

## 规矩

- 不打开 `_env` 下的密钥文件和名字文件。
- 卡住时自己定一个能改回来的做法，写进说明，接着做。
- 做完在 `镜头设计_v3/工作记录.md` 末尾追加一行。
