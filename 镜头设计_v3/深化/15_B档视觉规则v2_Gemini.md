### 一、22 页初审共性问题汇总（按出现频次降序）

1. **PPT 感与科学内容缺位（25+ 次）**：大面积用“单图标+一行字”、纯白圆角框清单、框线思维导图及塑料小人/钞票/日历/黑盒替代真实科研对象（蛋白结构、分子对接、真实论文与数据分布）。
2. **音画不同步与信息逻辑错位（20+ 次）**：标签/图形普遍提前抢跑或滞后于关键词；画面数字与台词不符、图例配色前后串台、输入流向画反、段尾尾音被硬截断。
3. **长时间死帧静止与音频空白（15+ 次）**：动作演完后停在末帧干等旁白（多处超 3–4.6 秒），背景大板无位移，句内句间存在 0.4–1.2 秒无效气口停顿。
4. **元素遮挡穿帮与页内硬切（12+ 次）**：新进零件直接压盖未退场的文字或旧图，转场元素在画边半截截留；同页段间整组元素瞬间清空、前后毫无承接。
5. **字体违规与出处行失配（8 次）**：表格数字、模型标注、节点卡混用无衬线体，正文违规使用手写体；出处行在错误段落提前挂出或残留上一段内容。

### 二、《B 档视觉规则 v2》（12 条可执行、可机检红线）

> **基准环境**：1920×1080（1080p）、原生 60 fps、全片 GSAP `timeline.seek(frame / 60)` 逐帧驱动。以下所有规则直接接入渲染后 CI 脚本（`check_v2.py`）自动验收，任意一条不通过即打回。

#### R01｜反 PPT 铁律：真实科学对象与主动作下限
- **规则**：禁止任何“单图标+一行字”、纯白圆角框清单、框线思维导图、纯二维进度条；禁用塑料小人、钞票、日历、通用烧瓶、写字黑盒代表科研过程。凡涉及蛋白、分子、文献、数据，必须真画出来（AlphaFold 3D 带状/表面模型与结合口袋、真实化学骨架/对接构象、带真实版式与图表剪影的实体论文页、真实数据分布/散点对照），并用零件实体的拆解、变形、组装、分子对接流或镜头微距推入来驱动叙事。
- **量化标准**：每 10 秒（600 帧）至少包含 **≥ 3 个主动作**（主动作定义：持续 ≥ 18 帧的几何连续变形、零件咬合/拆解、沿路径实体流动、镜头推拉变焦 ≥ 1.35×；单纯的 `opacity`/`scale` 弹出不算主动作）；通用抽象图标占比 **= 0%**。
- **怎么检查**：解析 GSAP timeline 事件表，按每 600 帧滑动窗口统计带 `morphSVG`/`motionPath`/`cameraZoom`/多件联动标签的主动作数（必须 ≥ 3）；资产引用扫描器核对 `bsprite/` 清单，凡命中黑名单（`mannequin`、`bill_stack`、`calendar`、`generic_flask`、`word_box`）直接报错。

#### R02｜动态连续性与静止帧上限
- **规则**：严禁任何“演完等声音”的死帧，L0 背景必须保持 Blender 真相机的连续缓慢推拉/横移，前景在任意语音段内保持持续叙事推进（拆分词点高亮、数据实时流动、结构微调）。
- **量化标准**：
  - 前景层（L2+L3+L4）连续完全静止上限 **≤ 18 帧（0.30 秒）**；
  - 两个“有效叙事变化”（非待机微动）的最大间隔 **≤ 45 帧（0.75 秒）**；
  - 句尾动作完成到下一句开声的停帧上限 **≤ 12 帧（0.20 秒）**；
  - L0 背景每 30 帧平均光流位移 **≥ 1.5 px**（禁止静帧底图）。
- **怎么检查**：导出纯前景 alpha 通道序列，计算相邻帧像素差异（MAE），连续 `MAE < 0.002` 超过 18 帧报错；读取 `keys/<段>.json` 与 GSAP 主事件时间戳，检查相邻事件间隔 ≤ 45 帧；对 L0 序列抽检每 30 帧 Farneback 光流均值 ≥ 1.5 px。

#### R03｜背景虚化上限与主体占空比
- **规则**：L0 大板必须保留可辨认的三维零件轮廓与冷暖材质关系，不得糊成纯色/渐变纸面；构图饱满，防止孤零零一个小图标漂在茫茫虚化背景中央。
- **量化标准**：
  - L0 焦外模糊等效高斯半径 **8–14 px**（上限 14 px，较 v1 的 18–25 px 明显收清晰）；
  - 前景有效视觉主体（L2+L3+L4 非透明像素的外接凸包面积）占画幅比例 **35%–65%**；
  - 纯露底空白区域占比 **≤ 30%**；除 T2/T5 转场帧外，单帧前景像素覆盖率不得低于 **18%**。
- **怎么检查**：对 L0 源素材计算 Laplacian 方差（限定在实测标定的 8–14 px 模糊区间内）；对成片每 15 帧抽检前景层透明通道，计算凸包占空比（须落入 35%–65%）及空屏帧数（连续空屏 > 0 帧即报错）。

#### R04｜字体全量统一与 1080p 最小字号
- **规则**：全片所有正文、标签、表格序号、坐标轴、芯片/卡片标注、模型说明 **100% 强制使用 Instrument Serif**，严禁混入任何无衬线体（Arial/Inter/Helvetica 等）；**Caveat 手写体仅限 L4 批注层**，禁止用作主标题、纯字卡或核心概念标签；所有文字保持水平摆正（允许旋转角度 `0°`，L4 批注除外且 `|θ| ≤ 6°`）。
- **量化标准（1080p）**：
  - 主标题 / 顶部大数字：**≥ 64 px**；
  - 标签 / 正文 / 节点文字：**≥ 36 px**（大写字母实测像素高 ≥ 28 px）；
  - 次级标注 / 表格内字 / 坐标轴：**≥ 26 px**（大写字母实测高 ≥ 20 px）；
  - 出处行：固定 **22 px**（大写字母实测高 ≥ 18 px）；
  - Caveat 手写批注：单页 **≤ 2 处**、每处 **≤ 4 个英文词**、字号 **34–44 px**，必须使用 DrawSVG 描边写出来。
- **怎么检查**：在 Remotion 渲染钩子中遍历 DOM/SVG 所有 `<text>` 和 HTML 文本节点的 `getComputedStyle()`，校验 `fontFamily` 仅含 `Instrument Serif` 或 `Caveat`（且 `Caveat` 必须挂在 `data-layer="L4"`），`fontSize` 和 `getBoundingClientRect().height` 达标，且任意文本不越界进入 `y > 940` 字幕禁区。

#### R05｜音画对词卡点窗口
- **规则**：所有标签、高亮框、关键零件出场、数字滚动停帧，必须严格绑定 `映射/keys/<段>.json` 的词级时间戳，严禁提前抢跑或话音落完才补动作。
- **量化标准**：
  - 文字标签/核心零件触发帧相对对应词起音帧误差 **[-2, +3] 帧**（-0.033s ~ +0.050s）；
  - 计数滚动停帧与旁白读完该数字的落点误差 **±2 帧**；
  - 一句话结束时，该句对应的所有展开/打勾/移动动画必须在句尾词结束后 **≤ 6 帧**内全部到位。
- **怎么检查**：运行 `check_sync.py`，直接比对 `keys/<段>.json` 词时间戳与 GSAP `label` 绑定的实际帧号，任意事件偏移超出 `[-2, +3]` 帧或句尾超时 > 6 帧直接判不过。

#### R06｜数字、图例与科学逻辑一致性
- **规则**：画面上出现的一切数字必须与当前旁白一致（旁白未提及的中间数字一律不上屏，旁白切换新数字时旧大数字须在同帧切换或淡出）；同一分子/药物/实体在同一段乃至相邻页的配色编码必须恒定，输入/输出流向必须符合真实科学因果。
- **量化标准**：
  - 同屏数字集合必须为当前句旁白数字的子集（差异项 **= 0**）；
  - 实体 ID 与颜色映射表（如 `001 → 银 #9A968C`、`048 → 金 #E2CFA0`）跨帧校验变更次数 **= 0**；
  - 状态切换（如 54 → 7）时，旧数字清场与新数字落位时间差 **≤ 4 帧**，且画面残留无关旧件数 **= 0**。
- **怎么检查**：自动化脚本抓取每帧 OCR/DOM 数字并与当前时间戳所在句子的正则数字表比对；检查场景 `entityColorMap` JSON，验证同 ID 实体在全段所有帧的填充色/贴图后缀一致。

#### R07｜页内段落交接禁硬切
- **规则**：严禁页内不同段落之间“前组元素整批瞬间消失、下组凭空弹出”的 PPT 换页感。段间必须采用以下三种承接之一：
  1. **锚点变形（Morph）**：保留上一段 1 个核心零件或分子，在画内连续变形/拆分演化出下一段结构；
  2. **推拉继承（Camera Push/Pull）**：舞台整体缩放或平移，把上一段的核心对象推到边缘/中心锚点，直接引出下一段；
  3. **甩镜（T2）**：整组舞台同向横移 1.2 个画宽并加横向动态模糊，下组从同方向甩入。
- **量化标准**：
  - 非 T1–T7 转场帧内，单帧同时消失的元素面积不得超过上一帧前景总面积的 **40%**；
  - 锚点变形或推拉过渡时长 **16–24 帧**；T2 甩镜固定 **7 帧**，位移 **2304 px**，`feGaussianBlur stdDeviation="40 0"`；
  - 锚点继承时，至少 **1 个**共享实体在交接前后位置连续（帧间跳变位移 **≤ 80 px**）。
- **怎么检查**：逐帧监测 DOM 元素卸载/透明度骤降比例（单帧下降 > 40% 且未声明 `T1–T7` 标记即报错）；检测段间交接帧前后是否存在连续 ID 锚点或标准 T2 模糊节点。

#### R08｜零遮挡与最小安全净距
- **规则**：文字与零件、零件与零件（非物理咬合/插接关系）、退场旧元素与新进元素之间严禁互压；退场元素必须彻底离开画框或透明度归零，严禁在画边截留半截字母或零件边角。
- **量化标准**：
  - 任意 L3/L4 文字外接矩形（Bounding Box）与任意非所属 L2 零件实心像素重叠面积 **= 0 px²**；
  - 文字框与相邻独立零件的最小边缘净间距 **≥ 20 px**；
  - 退场元素在新一组元素 `opacity > 0.05` 前必须达到 `opacity = 0` 或完全移出 `[0, 1920]×[0, 1080]`，画边截断残留 **= 0 帧**；
  - 任意元素不得压盖左下角出处行安全框。
- **怎么检查**：逐帧（或每 3 帧）导出 L3/L4 文本 Bounding Box 列表与 L2 非所属件 alpha 掩码，对文本框向外膨胀 20 px 后与 L2 掩码做按位与（AND），交集非零即输出帧号与冲突元素 ID；检测所有处于退场状态的节点在画框边界线（`x=0, x=1920, y=0, y=1080`）上的非零像素残留。

#### R09｜出处行固定规格与动态绑定
- **规则**：出处行内容必须与**当前秒画面正在展示的内容**严格一致（讲通用方法时不许提前挂后续论文作者出处，非自做对接画面严禁残留 `OUR RE-DOCKING`）；当页内内容切换数据源时，出处行同步淡换。
- **量化标准**：
  - 位置锁定：左下角 `x = 64 px`，底边 `y = 924 px`（严格位于 `y > 940` 字幕区之上），左对齐，单行最大宽 **≤ 960 px**；
  - 样式锁定：`Instrument Serif`、`22 px`、颜色 `#6E6B63`、底层配浅骨白磨砂托底条（`#F4F1EA` 透明度 `0.78`，圆角 `4 px`，左右内边距 `12 px`），保证任意背景亮度下对比度 **≥ 4.5:1**；
  - 切换过渡：随段首锚点同步交叉淡化 **8 帧**；全程顶层显示（z-index 高于 L2，低于全屏 T5 擦除）。
- **怎么检查**：核对脚本 `meta.citations[]` 分段时间区间是否覆盖当前帧画面类型；抽检 `[64, 896, 1024, 928]` 矩形区域与 L2 掩码的遮挡率（必须 = 0%）及 WCAG 文本对比度（≥ 4.5）。

#### R10｜音频停顿上限与尾音完整红线
- **规则**：施工方在导入 Remotion 前必须对配音做无损精剪，彻底裁掉无效吸气声、句内异常顿挫与句间长空白；段尾必须留足自然尾音衰减缓冲，严禁半截切字。
- **量化标准**：
  - 句内气口/逗号停顿 **≤ 0.18 秒（11 帧）**；
  - 句间换气空白 **≤ 0.30 秒（18 帧）**；
  - 段尾静音留白 **0.10–0.25 秒（6–15 帧）**；
  - 段尾最后 3 帧音频峰值电平必须 **≤ -45 dBFS**（确保最后一个词元已完全发完，无截断爆音）。
- **怎么检查**：渲染前跑 `check_audio.py`（基于 `ffmpeg silencedetect` / `librosa` RMS 能量）：扫描 `-40 dBFS` 以下静音段，句内 > 0.18s、句间 > 0.30s、段尾 > 0.25s 或最后 3 帧峰值 > -45 dBFS 直接阻断构建。

#### R11｜SVG 实体塑料材质与去扁平化
- **规则**：凡需要自绘的卡片、标尺、文献页、数据面板，严禁画成纯白扁平圆角框或细黑线表格；必须按 v1 五要素做成有厚度、倒角、镜面带与接触投影的“亮面模型板件/实体档案卡”，且所有色值严格限定在 5.2 色表内。
- **量化标准**：
  - 每个实心 SVG 板件必须具备：底部厚度面 **6–10 px**（亮度低 22%）、上左倒角白线 **1.5 px（不透明度 0.6）**、移动时滑过的 **12% 宽**镜面渐变带、接触阴影（模糊 14 px，偏移 `(+6, +10) px`，不透明度 0.28）；
  - 黑色描边轮廓线宽度 **= 0 px**；
  - 画面中所有 hex 色值必须 100% 命中 `kit_parts.py` 5.2 允许色表（误差 `ΔE = 0`）。
- **怎么检查**：静态 AST 扫描 TSX/SVG 代码，检查所有自定义板件组件必须继承 `<PlasticPlate>` 封装（强制带五要素参数），且正则提取全部颜色常量与 5.2 白名单比对。

#### R12｜同屏信息密度与视线引导闭环
- **规则**：同一时刻只允许聚焦一个叙事中心，防止多标签轰炸；失焦层自动退入纸面景深，焦点件边缘加亮边；严禁使用任何引导箭头、红圈、指点圆点。
- **量化标准**：
  - 同屏可见 L3 主标签数 **≤ 2 个**（不含固定出处行与坐标轴刻度）；
  - 非焦点层景深：`blur(2.2px)`、`brightness(0.82)`、`saturate(0.75)`；L3/L4 文字位于 `exempt` 层，模糊度恒为 **0 px**；
  - 焦点零件在对应词前 **8 帧**清晰化并点亮 **+0.3 档**轮廓亮边；`check_guides.py` V1–V14 必须全绿。
- **怎么检查**：逐帧统计 `data-role="label"` 且 `opacity > 0.1` 的节点数量（> 2 即报错）；全量执行 `映射/check_guides.py <段>` 校验 V1–V14。
