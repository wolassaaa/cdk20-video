# 《WORTH TESTING?》全片底乐施工设计方案（v10 定稿）

> **执行基准**：48 kHz / 24-bit 立体声，60 fps 视频帧率；代码仓库 `镜头设计_v3/音乐/synth/bed.py`（Python `numpy` + `scipy` + `pedalboard` + `pyloudnorm`）。  
> **已拍板选曲（定死）**：**W1 = Holly Herndon – *Godmother*（121.483 BPM）**；**W5 = The Weeknd – *Out of Time*（93.030 BPM）**。  
> **去“干/糙”核心原则**：① 全片分轨一律**先推子淡出干声、保留混响自然拖尾**，严禁 0 ms 硬截断；② 鼓组引入分层电影打击乐（深沉底鼓 + 宽厅军鼓 + 塑料“咔”边击 + 细腻踩镲 + 低音通鼓），并叠加微弱人性化力度偏移（±4% 确定性伪随机，种子 `seed=1007`）；③ 总线加入大片级空间层次（近场干声 + 中场板式混响 + 远场大厅混响）。  
> **时间锚点**：下表标称时长合计 `17:54`（1074 s），运行时 `bed.py` 严格从 `映射/master_v1.json` 读取实际段落起止帧，所有节拍通过连续速度图积分 `beat(t) = ∫(BPM(τ)/60)dτ` 生成。

## 一、逐章音乐表

### 统一符号与公共规范
- **调性校准**：下表列出各段基准调（小调表示）；`bed.py` 启动时读取 `音乐/拍子/<歌>.json` 中的 `tuning_cents`，对所有合成振荡器统一乘以 $2^{\text{tuning\_cents}/1200}$ 与原曲对齐。
- **和弦时值**：除特殊标注外，每个级数占 **2 小节**；所有 Pad 和弦转换采用 `120 ms` 等功率交叉声部过渡（Voice-leading），不重新硬触发起音。
- **16 分音符鼓型网格**（1 小节 = 16 步，按 4 拍分组 `1234 | 5678 | 9012 | 3456`）：
  - **底鼓行（KD）**：`K` = 重击（vel 1.0），`k` = 轻击（vel 0.62）
  - **军鼓/咔行（SN）**：`S` = 大厅军鼓实击（vel 0.92），`s` = 军鼓鬼音（vel 0.40），`R` = 塑料“咔”/边击（vel 0.72）
  - **踩镲行（HH）**：`H` = 闭镲重拍（vel 0.68），`h` = 闭镲轻拍（vel 0.36），`O` = 半开镲（vel 0.60）
  - **通鼓行（TM）**：`T` = 低通鼓（vel 0.85），`t` = 中通鼓（vel 0.68）（仅标于有通鼓或第 4 小节过门处）
  - `.` = 休止；`—` = 该乐器本段静音。
- **淡入淡出曲线函数**：
  - `s_curve`：Hann 半周期 $\frac{1-\cos(\pi u)}{2}$（用于电影感长进出）
  - `eq_pow`：等功率 $\sin(\frac{\pi}{2}u)$ / $\cos(\frac{\pi}{2}u)$（用于跨轨/原曲交叉淡化）
  - `exp_tail`：干声快速收束 + 混响自然释放（用于骤停/留白）

## 二、鼓与电影打击音色配方（Python 逐参数写死）

> 所有音色在 `48000 Hz` 浮点 `float64` 下生成，输出至 `perc.wav`（分轨内部按各件独立处理后再进鼓总线）。**低频单声道规则**：所有鼓组与 Boom 在 `120 Hz` 以下强制 `L == R`（单声道归中）。

### 1. 底鼓（Kick）
用于提供大片级下潜支撑，同时不与 Bass 的 60–110 Hz 打架。
- **振荡器**：
  - 主体层：正弦波，音高指数扫频 $f(t) = 46 + (145 - 46)e^{-t/0.024}$（单位 Hz，从 145 Hz 跌落至 46 Hz，24 ms 特征时间；其中第 1/8 章“柔底鼓”版本改为 115→48 Hz，时长缩短至 220 ms）。
  - 击打瞬态层（Click）：3.2 ms 白噪声经 4 阶 Butterworth 带通（`1800–4500 Hz`），增益 `-16 dB`。
- **包络**：Attack = `1.5 ms`（线性，防相位爆音），Hold = `12 ms`，Decay = `320 ms`（指数 $e^{-t/0.095}$），总长度截断于 `420 ms`（末 20 ms 余弦归零）。
- **滤波**：主振荡器串接 2 阶低通 `350 Hz`（防高频毛刺）；瞬态层串接高通 `1500 Hz`。
- **失真**：软饱和 `np.tanh(1.65 * x) / np.tanh(1.65)`（增加 90–180 Hz 温暖二次/三次谐波，小音响也能听见）。
- **混响与声像**：完全居中（Pan = `0.0`）；混响仅发送 `8%` 至鼓组短房间（`room_size=0.35, damping=0.75`，且混响返回前做 `180 Hz` 高通，禁止低频混响发浑）。

### 2. 军鼓（Snare）与塑料“咔”（Rim/Click）
兼顾“大片史诗感”与“模型零件世界”的物理质感。
- **2A. 大厅电影军鼓（网格中 `S` / `s`）**：
  - **振荡器（鼓腔体）**：正弦波从 `230 Hz` 跌至 `168 Hz`（$\tau = 18\text{ ms}$）+ 三角波 `340 Hz`（增益 `-9 dB`），振幅包络 Attack `1 ms` / Decay `130 ms`（$\tau = 45\text{ ms}$）。
  - **噪声（响弦）**：立体声独立白噪声（左右微去相关），经过 4 阶带通 `950–7800 Hz` + 峰值提升 `2200 Hz`（`+2.5 dB, Q=1.5`）；振幅包络 Attack `2 ms`，主衰减 `210 ms`（$\tau = 70\text{ ms}$），拖尾层（-14 dB）衰减 `420 ms`。
  - **混合比**：腔体 `0.55` + 噪声 `0.45`。
  - **失真**：`pedalboard.Distortion(drive_db=4.5)` 过后再压软削波 `tanh(1.3 * x)`。
  - **混响与声像**：Pan = `0.0`（噪声微宽 ±15%）；主混响 `pedalboard.Reverb(room_size=0.72, damping=0.48, wet_level=0.28, dry_level=0.85, width=0.85)`，混响湿声经过高通 `280 Hz` + 低通 `5200 Hz`（经典电影军鼓暗大厅尾）。鬼音 `s` 时低通再降到 `3200 Hz`、干湿比降至 `wet=0.14`。
- **2B. 塑料“咔”（网格中 `R`）**：
  - **振荡器（塑料共振体）**：正弦波 `1820 Hz`（每次击打在 `±45 Hz` 内确定性微变，防机械感）+ `3150 Hz`（`-6 dB`），包络 Attack `0.5 ms` / Decay `28 ms`（$\tau = 9\text{ ms}$）。
  - **噪声（水口弹断瞬态）**：白噪声 `9 ms`，4 阶带通 `2200–6200 Hz`，Attack `0.3 ms` / Decay `8.5 ms`。
  - **失真**：`np.tanh(2.0 * x)` 增强脆感。
  - **混响与声像**：Pan = `+0.18`（略偏右，与踩镲错位）；短板混响 `room_size=0.38, damping=0.55, wet_level=0.16, dry_level=0.92`。

### 3. 踩镲（Hi-Hat：闭镲 `H`/`h` 与半开镲 `O`）
不采用粗糙纯白噪声，使用**经典 6 频金属方波集群 + 滤波粉红/白噪声**，消除沙哑廉价感。
- **振荡器（金属泛音群）**：6 个非谐波方波相加，基频定死为 `[317, 463, 619, 827, 1087, 1453] Hz`（经 `10 ms` 极短高通防直流）。
- **噪声**：白噪声与金属群按 `0.60 : 0.40` 混合。
- **滤波**：串联 4 阶高通 `6200 Hz` + 2 阶低通 `13500 Hz`（切掉刺耳超高频）+ 轻微带通峰 `9200 Hz`（`+2 dB, Q=2.0`）。
- **包络**：
  - 闭镲 `H`/`h`：Attack = `1.0 ms`，Decay = `48 ms`（$\tau = 16\text{ ms}$），总长 `75 ms`。
  - 半开镲 `O`：Attack = `1.5 ms`，Decay = `240 ms`（$\tau = 85\text{ ms}$），总长 `320 ms`（下一个闭镲触发时执行 `15 ms` 抢音静音 Choke）。
- **失真**：`pedalboard.Distortion(drive_db=1.5)`。
- **混响与声像**：Pan = `-0.22`（略偏左）；`Reverb(room_size=0.45, damping=0.60, wet_level=0.14, dry_level=0.92, width=0.70)`。

### 4. 电影通鼓（Tom：低通 `T` / 中通 `t`）
用于第 3/4/5 章情绪爬升与章节过门，提供 Hans Zimmer 式重击厚重感。
- **振荡器**：
  - 低通 `T`：正弦波 `132 Hz → 72 Hz`（$\tau = 42\text{ ms}$）+ 三角波八度泛音 `264 Hz → 144 Hz`（`-12 dB`）。
  - 中通 `t`：正弦波 `185 Hz → 108 Hz`（$\tau = 35\text{ ms}$）+ 三角波八度泛音（`-12 dB`）。
- **噪声（鼓槌敲皮声）**：`14 ms` 粉红噪声，带通 `600–2400 Hz`，增益 `-14 dB`。
- **包络**：Attack = `2.0 ms`，Decay = `380 ms`（低通 $\tau=130\text{ ms}$；中通 $\tau=105\text{ ms}$）。
- **滤波**：2 阶低通 `1800 Hz`（确保沉厚不抢人声）。
- **失真**：`np.tanh(1.8 * x)`。
- **混响与声像**：低通 Pan = `+0.28`，中通 Pan = `-0.28`（立体声滚奏移动）；大厅混响 `Reverb(room_size=0.80, damping=0.42, wet_level=0.34, dry_level=0.82, width=0.95)`，湿声高通 `140 Hz`。

### 5. 低频冲击与上升音（Sub Boom & Cinematic Riser）
- **5A. 低频冲击（Sub Boom）**（用于 W0 第 3 击、W1 盒盖、W4 闩落、重大转场）：
  - **振荡器**：纯正弦波 `88 Hz → 36 Hz`（长扫频 $\tau = 260\text{ ms}$）+ 叠层锯齿波（与当前章根音同音高，经 4 阶低通 `220 Hz`，增益 `-10 dB`）。
  - **噪声冲击头**：`35 ms` 粉红噪声，带通 `180–900 Hz`，增益 `-8 dB`。
  - **包络**：Attack = `4 ms`，Hold = `60 ms`，Decay = `1800 ms`（$\tau = 620\text{ ms}$）。
  - **失真**：仅对 `80 Hz` 以上支路施以 `np.tanh(2.2 * x)`，保留 `36–80 Hz` 纯净下潜。
  - **混响**：Pan = `0.0`；`Reverb(room_size=0.88, damping=0.50, wet_level=0.30, dry_level=0.88, width=1.0)`，混响返回前 `110 Hz` 高通。
- **5B. 上升音（Cinematic Riser）**（分短款 `1.2 s` 与长款 `3.8 s` 两种）：
  - **振荡器**：双失谐锯齿波（±12 cents）从当前调根音向上滑音 1 个八度（指数频率爬升），叠加立体声白噪声。
  - **滤波**：4 阶共振低通滤波器（`Q = 2.8`），截止频率随时间指数从 `180 Hz` 扫至 `5200 Hz`；末尾保留 `120 Hz` 高通防闷。
  - **包络**：幅值按 $u^{2.4}$ 指数爬升至顶点（`-3 dBFS`），顶点处做 **`35 ms` 快速截停（Air-gap 吸气感）**，仅留混响尾巴带入下一拍重击。
  - **混响**：`Reverb(room_size=0.85, damping=0.35, wet_level=0.42, dry_level=0.75, width=1.0)`。

### 6. 鼓总线与底乐大片润色参数（防干涩统一处理）
- **鼓总线（`perc.wav` 输出前）**：
  - 总线胶水压缩：`pedalboard.Compressor(threshold_db=-16.0, ratio=2.8, attack_ms=18.0, release_ms=110.0)`（放过瞬态、黏合空间）。
  - 柔饱和：`np.tanh(1.15 * x)`。
- **其他三轨升级点（针对原 v9 “太干” 修正）**：
  - **Pad**：由 2 锯齿升级为 **4 锯齿微失谐**（`-11, -4, +4, +11 cents`，分置左右声像 `±0.65 / ±0.25`）+ 低八度正弦；混响调大至 `room_size=0.78, damping=0.45, wet_level=0.36, width=0.95`；叠加极缓 LFO（`0.12 Hz`）轻微摆动低通截止频率 `±140 Hz`。
  - **Bass**：正弦 + 三角（`1:0.35`）后加 `np.tanh(1.35 * x)` 增加中低频存在感，低通设在 `220 Hz`（2 阶），保证笔记本外放也能听出贝斯线。
  - **Arp**：每个十六分音符加入 `1/8 附点立体声延迟`（Feedback `0.22`，Wet `0.18`，延迟反馈路径高通 `450 Hz` / 低通 `2200 Hz`），彻底消除干涩点状感。
