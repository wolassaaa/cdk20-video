2. **前面没有能插卡的缝。** 1-01→1-02 是 "…die of liver cancer." → "That's 1,412 people…"，1-04→1-05 是一问一答，插进去会把一句话拆开。1-11→2-01 是剧本原本留给片名的位置（剧本 W1："Half a beat of silence, then the title slams in"）。

5. **W0 只加长到 6 拍。** 原来 2 秒、没声音，三下太快看不清。6 拍让三下打击各有半秒，再用两拍把全板灯亮起来、交给 A。

**片头内三个接点，没有一处硬切：**

**新代码：** `镜头设计_v3/inserts/title_names.py`（进仓库，里面没有任何名字）。

```python
def load_names(root="D:/。hkbu/molecular science", draft=False) -> dict:
    """返回 {"A": 名字, ...}。只在内存里用，不写盘，不打印内容。"""
```

读法：

1. 每位组员找 `人员素材啊/{M}/名字*.txt`，按文件名排序取第一个。
2. 用 `utf-8-sig` 读，逐行看：去掉首尾空白；如果行里有 `:` 或 `：`，丢掉它和它前面的标签；去掉中文字符和多余空格；剩下的至少有 3 个拉丁字母、没有数字，就是名字。取第一个这样的行。学号行（纯数字）不读。
3. 检查：3–40 个字符，只能有字母、空格、连字符、撇号、句点。
4. 只打印 `A ok (3 words, 12 chars)` 或 `B missing` 这样的行，**从不打印名字本身**。
5. 有人缺：`draft=False` 时 `raise SystemExit("names missing: B, C")`；`draft=True` 时用 `Member B` 占位，并打印 `B draft placeholder`。

**渲染：** W1 镜头脚本 `镜头设计_v3/inserts/shot_w1_title.py`（进仓库）在 Blender 里 `from title_names import load_names`，把结果直接传给 `h20_kit_box(K, names=...)`。不经过任何中间文件。
