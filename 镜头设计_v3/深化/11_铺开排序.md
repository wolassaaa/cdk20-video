## 零、结论

1. **分档**：全片 70 段加 1 个 AI 角色插段。A 档（Blender 三维）28 段，其中 3 段已做完；B 档（Remotion + SVG + GSAP）37 段，另加已做完的 AI 插段；C 档（保留 v9）5 段。
2. **卡脖子的是施工，不是显卡。** v10 要新渲的三维约 22,000 帧，按实测 3.5 秒一帧、两路并行，连试渲和返工余量一共约 16 小时挂钟；从现在到 11-23 08:00 有 62 小时。显卡排得进，而且有富余。两条施工线的人工时算下来基本排满（见第四节），所以降级点都设在施工进度上。
3. **顺序**：先做插座三段（3-04、5-04、W4，真分子也在这三段露出），再做 17 组出镜段，再做 W3、W2、3-03、3-02。B 档由另一条线同时铺，先做和插座有关的页。
4. **保底**：任何一段到点没做完、没过机检，就用 v9 的那一段。v9 已经是完整可交的片子，所以 v10 在 11-23 晚一定交得出。
5. **原先想做三维、这次降到 B 的段**：5-01、5-08（Kd 秤）、4-06、4-07（循环轨道和芯片）、第 6 章记分板等共 22 处钻取里的 15 处。原因是人工时不够，不是显卡不够。5-08、5-01 是升档候补，施工线提前空出来才做。

## 三、渲染预算

### 用的数

- 每帧 3.5 秒：W1 实测（16 采样，和另一个 Blender 共用显卡）。出镜段背景层在同样条件下也是约 3.5 秒；3-01 单独跑 32 采样约 3 秒。全部按 3.5 秒算，这是两路同时开时每一路的速度。
- 两路并行，挂钟时间 = 路时 ÷ 2。
- 设置：1080p60，Cycles + OptiX，16 采样 + OptiX 降噪，运动模糊开。
- Remotion：3002 帧约 3 分钟，走 CPU。

### 显卡富余怎么用（不让它闲）

## 五、B 档统一视觉规则

目的：B 档的页面和 A 档的三维亮面玩具世界放在一起，看不出是两套东西。施工方照下面的规格做，不用再做设计判断。

### 5.1 总原则：零件用 Blender 渲出来的图，Remotion 只管动

B 档不用 SVG 去"画"塑料零件。画面分五层，从下到上：

| 层 | 内容 | 怎么来 |
|---|---|---|
| L0 背景 | 虚化的三维大板 | Blender 真渲。7 个区各一条 720 帧的慢移镜头（12 秒，来回播放），焦外 18–25 px，比 A 档板面暗 0.3 档。存 `G:/cdk20/work/bplate/zone<N>/` |
| L1 影子 | 每个零件的接触阴影 | 椭圆，模糊 14 px，不透明度 0.28，相对零件偏移（+6, +10）px；零件浮起时每升高 10 px 阴影放大 4%、淡 0.03 |
| L2 零件和机构 | 零件贴图；SVG 画的机构线、路径、刻度、表格、计数 | 零件贴图由 Blender 渲带透明通道的 PNG，灯光和大板同一套（主光左上、暖色），每个零件 3–5 个姿态，按 2 倍尺寸出。存 `G:/cdk20/work/bsprite/<零件>/` |
| L3 标签 | 标签、出处行 | Instrument Serif |
| L4 批注 | 手写批注 | Caveat，用描边路径画出来 |

最上面盖一层全画面颗粒，用出镜段合成的同一个颗粒函数。

页面不留大片空白：对焦主体占画面 25%–60%，纯背景不超过 35%（01 第三节 A1、A2 照用）。

### 5.2 配色（只许用这些，取自 `kit_parts.py`）

| 用途 | 色值 |
|---|---|
| 背景台面 | `#F3EEE6` |
| 骨白（料杆、白件、路） | `#F4F1EA` |
| 克莱因蓝（CDK20、插座） | `#002FA7` |
| 蓝高光 | `#3D6BE6` |
| 红（插孔红环、描红、红尾巴、"?"） | `#C8102E` |
| 金（钥匙、假插头） | `#E2CFA0` |
| 黑（芯片） | `#1E1E20` |
| 字（深） | `#1F1E1C` |
| 字（浅，印在深色件上） | `#F7F4EE` |
| 灰字、未达成的状态 | `#9A968C` |
| 绿（打勾） | `#5E8A64` |
| 次要说明字 | `#6E6B63` |

ATP 真插头的透明黄从 `kit_parts.py` 的 `K.yellow` 读，不另选色。红色只留给内容，引导不用红。不许出现表外的颜色、渐变彩虹、霓虹发光。

### 5.3 SVG 件的材质感（表格、牌子、刻度这些自己画的件）

每个实心 SVG 件都要做足这五样，做出来是一块亮面塑料牌，不是一个色块：

1. 厚度：底下加一条 6–10 px 的侧面，颜色比正面暗 22%。
2. 倒角高光：沿上边和左边内缩 1.5 px 画一条白线，不透明度 0.6。
3. 镜面带：左上到右下一条白色线性渐变，宽度为件宽的 12%，不透明度 0.35 到 0。件动的时候这条带跟着滑过一次。
4. 暗部：右下内阴影，正片叠底 0.18。
5. 接触阴影：照 L1。

不画黑色描边轮廓。字是"刻"上去的：字色用上表的深字或浅字，下方 1 px 加一条亮线。挂在料杆上的件要画浇口（一个小锥），件弹下来时浇口断开。

### 5.4 动作：GSAP，逐帧寻址

- GSAP 时间线一律暂停，用 `useCurrentFrame()` 驱动 `timeline.seek(frame / fps)`。不许自动播放，不许用 CSS transition 和 CSS animation，不许用没有固定种子的随机数。套件里提供一个 `useGsapTimeline(build)`，各页只写 `build`。
- T4_remotion 的 `package.json` 里现在没有 gsap，套件第一步先装（`pnpm add gsap`，版本写死）。
- 所有动作的起点从 `映射/keys/<段>.json` 读，落在词上，误差 2 帧以内。不手写帧号。
- 统一的缓动和时长：

| 动作 | 做法 |
|---|---|
| 预备 | 主动作前 6 帧，反方向走行程的 8% |
| 落位 | 18 帧，`back.out(1.6)`，过冲约 8%，回弹不超过两次 |
| 次级动作 | 主动作落位后 6 帧内，旁边一样东西抖一下（浇口、料杆、相邻件），幅度 3 px 以内 |
| 一组东西依次出现 | 每个错开 4 帧 |
| 沿料杆或路走 | MotionPath，速度不超过每秒 0.6 个画面宽 |
| 标签的字 | SplitText 按词拆，每词错开 3 帧，上移 12 px 淡入 |
| 手写批注 | DrawSVG 描出，24–36 帧 |
| 计数 | 数字轮滚动，停的那一帧落在词上 |
| 待机 | 每个零件登记一个微动（慢转 ±2°、上下浮 2 px），相邻两个事件间隔不超过 2.5 秒 |

- 位图不做后期推拉。零件贴图按 2 倍出，最多放到 1.6 倍；L0 背景不缩放，它的移动是 Blender 里真相机走出来的。

### 5.5 视线引导

照 `05_视线引导.md` 第四节，用 `kit.jsx` 里已经做好的组件：

- `guidePlan(K)` 从事件表算引导表；`<Lens>` 加 `<Layer>` 做纸面景深：不在焦点上的层模糊 2.2 px、亮度 0.82、饱和度 0.75；字放在 `exempt` 层，永远不虚。
- 被点名的零件在词前 8 帧变清楚，同时零件贴图边缘加一圈 +0.3 档的亮边（代替三维的轮廓光）。
- `nudge` 做浇口预颤：词前 6 帧，位移不超过 6 px。
- `<RunnerPulse>` 做走料：只在新目标在画外、或离当前焦点超过画面宽 35% 时用，每句最多一次，用料杆本色提亮，不用红。
- 不加箭头、圈、点。`Bead` 保持返回 null。
- 做完跑 `映射/check_guides.py <段>`，V1–V14 全过。

### 5.6 转场 T1–T7 在 B 档里怎么做

每个接点在该段事件表的镜头行里写上代号。全片不许硬切，不许简单淡化。
