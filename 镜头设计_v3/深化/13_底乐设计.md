## 一、逐章音乐表

### 公共规范与网格符号
- **调音校准**：读取 `keys.json` 中各曲 `tuning_cents`，该底乐段所有振荡器频率统一乘以 $2^{\text{tuning\_cents}/1200}$，跨段平滑过渡（1 小节内线性插值）。
- **和弦时值**：除特别标注外，每个级数占 **2 小节**；Pad 换和弦统一用 `120 ms` 等功率声部交叉（Voice-leading），不重触发硬起音。
- **16 分音符鼓型网格**（1 小节 = 16 步，按 4 拍分组 `1234 | 5678 | 9012 | 3456`）：
  - **底鼓（KD）**：`K` = 重击（vel `1.00`），`k` = 轻击（vel `0.62`）
  - **军鼓/咔（SN）**：`S` = 大厅军鼓实击（vel `0.92`），`s` = 军鼓鬼音（vel `0.40`），`R` = 塑料“咔”边击（vel `0.72`）
  - **踩镲（HH）**：`H` = 闭镲重拍（vel `0.68`），`h` = 闭镲轻拍（vel `0.36`），`O` = 半开镲（vel `0.60`）
  - **通鼓（TM）**：`T` = 低通鼓（vel `0.85`），`t` = 中通鼓（vel `0.68`）；`.` = 休止；`—` = 本段静音。
- **淡入淡出曲线**：`s_curve`（Hann 半周期 $\frac{1-\cos(\pi u)}{2}$，电影长进出）、`eq_pow`（等功率 $\sin/\cos(\frac{\pi}{2}u)$，跨轨/原曲交叉）、`exp_tail`（干声快收、保留混响拖尾，用于断点留白）。

## 二、鼓与电影打击音色配方（Python 逐参数写死）

> 所有音色在 `48000 Hz` 浮点 `float64` 下生成，输出至 `perc.wav`（各件独立处理后再进鼓总线）。**低频单声道规则**：所有鼓组与 Boom 在 `120 Hz` 以下强制 `L == R`（单声道归中）。每次击打施加确定性人性化微调：力度 `±4%`（`seed=1007`）、时间微偏移 `±3 ms`（仅施加在踩镲与鬼音军鼓，底鼓与主军鼓严格锁拍）。

### 1. 底鼓（Kick：`K` / `k`）
- **振荡器**：
  - 主体层：正弦波指数扫频 $f(t) = 46 + (145 - 46)e^{-t/0.024}$ Hz（24 ms 跌落至 46 Hz；第 1/8 章与彩蛋的“柔底鼓”版本改为 `115 → 48 Hz`，总长缩短至 `220 ms`）。
  - 击打瞬态层（Click）：`3.2 ms` 白噪声经 4 阶 Butterworth 带通（`1800–4500 Hz`），增益 `-16 dB`。
- **包络**：Attack = `1.5 ms`（线性，防相位爆音），Hold = `12 ms`，Decay = `320 ms`（指数 $e^{-t/0.095}$），总长截断于 `420 ms`（末 `20 ms` 余弦归零）。
- **滤波**：主体串接 2 阶低通 `350 Hz`；瞬态层串接 2 阶高通 `1500 Hz`。
- **失真**：软饱和 `np.tanh(1.65 * x) / np.tanh(1.65)`（补足 90–180 Hz 谐波，小扬声器也能听见底鼓）。
- **混响与声像**：Pan = `0.0`；仅发送 `8%` 至鼓组短房间（`room_size=0.35, damping=0.75`，混响返回前做 `180 Hz` 高通，严禁低频发浑）。

### 2. 军鼓（Snare：`S` / `s`）与塑料“咔”（Rim/Click：`R`）
- **2A. 大厅电影军鼓（`S` / `s`）**：
  - **振荡器（鼓腔）**：正弦波 `230 → 168 Hz`（$\tau = 18\text{ ms}$）+ 三角波 `340 Hz`（`-9 dB`），包络 Attack `1.0 ms` / Decay `130 ms`（$\tau = 45\text{ ms}$）。
  - **噪声（响弦）**：立体声独立白噪声，4 阶带通 `950–7800 Hz` + 峰值提升 `2200 Hz`（`+2.5 dB, Q=1.5`）；Attack `2.0 ms`，主衰减 `210 ms`（$\tau = 70\text{ ms}$），拖尾层（`-14 dB`）衰减 `420 ms`。
  - **混合比**：腔体 `0.55` + 噪声 `0.45`。
  - **失真**：`pedalboard.Distortion(drive_db=4.5)` 后接 `np.tanh(1.3 * x)`。
  - **混响与声像**：Pan = `0.0`（噪声微宽 `±15%`）；大厅混响 `pedalboard.Reverb(room_size=0.72, damping=0.48, wet_level=0.28, dry_level=0.85, width=0.85)`，湿声经高通 `280 Hz` + 低通 `5200 Hz`。鬼音 `s` 时低通降至 `3200 Hz`、`wet_level=0.14`。
- **2B. 塑料“咔”（`R`，与零件模型同材质）**：
  - **振荡器**：正弦波 `1820 Hz`（每次击打在 `±45 Hz` 内确定性微变，防机械重复）+ `3150 Hz`（`-6 dB`），Attack `0.5 ms` / Decay `28 ms`（$\tau = 9\text{ ms}$）。
  - **噪声（水口弹断）**：白噪声 `9 ms`，4 阶带通 `2200–6200 Hz`，Attack `0.3 ms` / Decay `8.5 ms`。
  - **失真**：`np.tanh(2.0 * x)` 增强脆感。
  - **混响与声像**：Pan = `+0.18`（略偏右）；短板混响 `room_size=0.38, damping=0.55, wet_level=0.16, dry_level=0.92`。

### 3. 踩镲（Hi-Hat：闭镲 `H`/`h` 与半开镲 `O`）
- **振荡器（6 频金属方波群）**：6 个非谐波方波相加，基频定死 `[317, 463, 619, 827, 1087, 1453] Hz`（消除纯白噪声廉价沙哑感）。
- **噪声**：白噪声与金属群按 `0.60 : 0.40` 混合。
- **滤波**：4 阶高通 `6200 Hz` + 2 阶低通 `13500 Hz` + 轻峰值 `9200 Hz`（`+2.0 dB, Q=2.0`）。
- **包络**：闭镲 `H`/`h`：Attack `1.0 ms` / Decay `48 ms`（$\tau=16\text{ ms}$），总长 `75 ms`；半开镲 `O`：Attack `1.5 ms` / Decay `240 ms`（$\tau=85\text{ ms}$），总长 `320 ms`（遇下一闭镲执行 `15 ms` Choke 静音）。
- **失真与混响**：`pedalboard.Distortion(drive_db=1.5)`；Pan = `-0.22`；`Reverb(room_size=0.45, damping=0.60, wet_level=0.14, dry_level=0.92, width=0.70)`。

### 4. 电影通鼓（Tom：低通 `T` / 中通 `t`）
- **振荡器**：低通 `T` 正弦 `132 → 72 Hz`（$\tau=42\text{ ms}$）+ 三角八度泛音（`-12 dB`）；中通 `t` 正弦 `185 → 108 Hz`（$\tau=35\text{ ms}$）+ 三角八度泛音（`-12 dB`）。
- **噪声（鼓槌敲皮）**：`14 ms` 粉红噪声，带通 `600–2400 Hz`，增益 `-14 dB`。
- **包络与滤波**：Attack `2.0 ms`，Decay `380 ms`（低通 $\tau=130\text{ ms}$；中通 $\tau=105\text{ ms}$）；2 阶低通 `1800 Hz`。
- **失真与混响**：`np.tanh(1.8 * x)`；低通 Pan = `+0.28`，中通 Pan = `-0.28`；大厅混响 `Reverb(room_size=0.80, damping=0.42, wet_level=0.34, dry_level=0.82, width=0.95)`，湿声高通 `140 Hz`。

### 5. 低频冲击与上升音（Sub Boom & Cinematic Riser）
- **5A. Sub Boom**（W0 第 3 击、W1 外框断开、W4 闩落、重大转场）：
  - 振荡器：正弦 `88 → 36 Hz`（$\tau=260\text{ ms}$）+ 当前章根音锯齿波（4 阶低通 `220 Hz`，`-10 dB`）+ `35 ms` 粉红噪声（带通 `180–900 Hz`，`-8 dB`）。
  - 包络与失真：Attack `4 ms` / Hold `60 ms` / Decay `1800 ms`（$\tau=620\text{ ms}$）；仅 `80 Hz` 以上支路做 `np.tanh(2.2 * x)`，保留 `36–80 Hz` 纯净下潜。
  - 混响：Pan = `0.0`；`Reverb(room_size=0.88, damping=0.50, wet_level=0.30, dry_level=0.88, width=1.0)`，湿声高通 `110 Hz`。
- **5B. Cinematic Riser**（短款 `1.2 s` / 长款 `3.8 s`）：
  - 振荡器：双失谐锯齿（`±12 cents`）从当前调根音上滑 1 个八度 + 立体声白噪声。
  - 滤波与包络：4 阶共振低通（`Q=2.8`）截止频率指数扫频 `180 → 5200 Hz`（末端串 `120 Hz` 高通）；振幅按 $u^{2.4}$ 爬升至 `-3 dBFS`，顶点处做 **`35 ms` 快速截停（Air-gap 吸气感）**，仅留混响尾带入重击。
  - 混响：`Reverb(room_size=0.85, damping=0.35, wet_level=0.42, dry_level=0.75, width=1.0)`。

### 6. 鼓总线与其余三轨润色（解决 v9“干、糙”）
- **鼓总线（`perc.wav` 输出前）**：胶水压缩 `pedalboard.Compressor(threshold_db=-16.0, ratio=2.8, attack_ms=18.0, release_ms=110.0)` + 柔饱和 `np.tanh(1.15 * x)`。
- **Pad**：升级为 4 锯齿微失谐（`-11, -4, +4, +11 cents`，声像 `±0.65 / ±0.25`）+ 低八度正弦；混响 `room_size=0.78, damping=0.45, wet_level=0.36, width=0.95`；加 `0.12 Hz` 慢 LFO 轻摆低通截止频率 `±140 Hz`。
- **Bass**：正弦 + 三角（`1 : 0.35`）后做 `np.tanh(1.35 * x)`，2 阶低通 `220 Hz`（增强中低频谐波，笔记本外放可听）。
- **Arp**：每个音符接 `1/8 附点立体声延迟`（Feedback `0.22`，Wet `0.18`，反馈路径带通 `450–2200 Hz`），消除点状干涩。

## 三、给人声让位规则（Vocal Ducking & EQ Carving）

全套让位在 Python 中**完全离线逐采样计算增益与滤波包络**，杜绝实时压缩器的抽吸感，且每次渲染 bit-exact 一致。

### 1. 动态侧链压低（离线增益计算机）
- **侧链检测信号（Key Input）**：读取对齐后的人声分轨 `voice.wav` → 4 阶 Butterworth 带通 `120 Hz – 6000 Hz`（屏蔽喷麦次低频和房间空气底噪误触发）→ 按 `20 ms` 滑动窗算 RMS 电平 $L_{\text{rms}}(t)$（dBFS）。
- **前瞻平滑（Lookahead）**：人声包络整体**前移 `30 ms`**，确保人声第一个音节出来之前底乐已经平稳让出，不吞字头。
- **侧链参数（定死）**：
  - **触发阈值（Threshold）**：`-34.0 dBFS`（实测归一化到 `-16 LUFS` 的人声，正常吐字在 `-24` 至 `-14 dBFS`，换气/环境底噪在 `-42 dBFS` 以下）。
  - **压缩比（Ratio）**：`4.0 : 1`，带 **`6.0 dB` 软拐点（Soft Knee）**（`-37` 到 `-31 dBFS` 平滑过渡，防止突兀台阶）。
  - **起动时间（Attack）**：`120 ms`（一阶指数时间常数 $\tau_a = 40\text{ ms}$，搭配 `30 ms` 前瞻，平滑下沉）。
  - **保持时间（Hold）**：`250 ms`（防词与词之间的短停顿引起底乐反复抬头“抽风”）。
  - **释放时间（Release）**：`480 ms`（一阶指数时间常数 $\tau_r = 160\text{ ms}$）；仅当句间静音持续 `≥ 0.80 s` 时允许底乐完整回升至静态电平。
  - **压低上限（Max Attenuation）**：
    - **普通 VO 讲解段**：底乐总线最大压低 **`-8.0 dB`**。
    - **ON-CAM 出镜段**（`master_v1.json` 中 `kind == "ON-CAM"`，手机收音带房间混响）：静态基线再降 **`-2.0 dB`**，说话时最大再压低 **`-8.5 dB`**（合计较 VO 静默期低 `10.5 dB`）。
    - **片尾彩蛋（多人快节奏对话）**：因 4 个 AI 角色语速快、笑声多，静态基线比正片高 `+1.0 dB`，但起动更快（Attack `80 ms` / Hold `180 ms` / Release `320 ms`），最大压低 **`-7.0 dB`**。
- **分轨差异化压低权重**（不“一刀切”，保留律动骨架）：
  - `pad`：`1.00 ×`（全额压低 `-8.0 dB`，给中频腾位置）
  - `arp`：`1.15 ×`（压低 `-9.2 dB`，且动态关闭高频滤波，见第 3 条）
  - `bass`：`0.65 ×`（仅压 `-5.2 dB`，维持底部温暖支撑，不因人声开口显得发虚）
  - `perc`：`0.75 ×`（压 `-6.0 dB`，保留清晰但克制的鼓点脉搏）
  - `event`：`0.30 ×`（仅压 `-2.4 dB`，且触发时避开重读词，保证卡点听得见）

### 2. 静态频段挖空（Static EQ Carving，全片常驻）
对底乐各轨及总线在进入最终混音前施加固定零相位/最小相位参量均衡，彻底清出人声清晰度核心区：

| 作用对象 | 滤波器类型 | 中心/截止频率 | 增益 | Q 值 / 斜率 | 目的 |
|---|---|---|---|---|---|
| **底乐总线（`bed_mix`）** | 高通 HPF | `30 Hz` | — | 4 阶（24 dB/oct） | 切次声直流，释放真峰值余量 |
| **底乐总线（`bed_mix`）** | 宽钟形衰减 Bell | `2400 Hz` | **`-4.0 dB`** | `Q = 0.85`（覆盖 `1.4–4.2 kHz`） | 清出英文辅音清晰度与人声明亮度核心带 |
| **底乐总线（`bed_mix`）** | 轻高频搁架 High-Shelf | `8500 Hz` | **`-1.5 dB`** | `Q = 0.70` | 柔化金属感，为人声齿音空气感让路 |
| **`pad` + `arp` 轨** | 钟形衰减 Bell | `280 Hz` | **`-2.5 dB`** | `Q = 1.20`（覆盖 `190–400 Hz`） | 避开男声/女声基频与胸腔共鸣，防闷糊 |

| **`bass` 轨** | 钟形衰减 Bell | `52 Hz` | **`-2.0 dB`** | `Q = 2.00` | 给底鼓 46–55 Hz 中心冲击让出空间（Kick/Bass 分家） |

### 3. 动态 EQ 与滤波联动（仅人声开口时触发）
由同一条侧链控制包络 $g_{\text{duck}}(t) \in [0, 1]$（`0` = 无人说话，`1` = 正在说话）驱动：
- **`arp` 动态低通**：无人说话时截止频率维持该段设计值（`2200–3600 Hz`）；人声出现时平滑下压至 **`1350 Hz`**（2 阶低通），句子空隙 `≥ 0.80 s` 再重新打开，防止十六分亮音切碎英文语音。
- **`pad` 动态中频凹槽**：人声出现时，额外叠加一个动态钟形衰减 `1800 Hz, -2.5 dB, Q = 1.1`，实现“人声开口瞬间背景自动退后半步”的电影混音纵深感。
- **W 段原曲让位（仅预叠/淡出交叉期）**：W 段正片期间无人声，不做压低；在 W 段前 `2 小节` 预叠期与后 `1 小节` 淡出期（与 3-09、4-09、8-07、2-01、4-01、4-10、5-10 人声重叠），原曲自动套用本节静态 `2400 Hz -4 dB` 挖空 + 低通 `400–600 Hz`（见逐章表）。

## 四、画面事件卡点规范（Audio–Visual Sync & Lead Time）

所有卡点音频直接读取 `映射/keys/<段>.json`（事件帧号，60 fps）与转场清单，对照表保存在 `镜头设计_v3/音乐/synth/music_events.json`。**基本同步法则**：
- **60 fps 换算**：`1 帧 = 16.667 ms`；下表“提前量（帧）”为负值表示**音频起始点早于画面目标帧**，用于抵消人耳听觉起振感知延迟或让 Riser 顶点刚好撞上视觉冲击帧。
- **避让重读词规则**：非转场类事件音（拨弦、数字落定、塑料咔）若落在 `master_v1.json` 中任意英文重读词起点的 `±5 帧（±83 ms）` 内，自动再前移至该词起点前 **`-5 帧（-83 ms）`**；转场 T1–T7 与 W 段重拍不避让（本身位于句缝或无对白帧）。
- **和弦抢拍吸附规则**：若章节/段落转场帧距下一条小节线 `≤ 0.5 拍`，Pad 和弦切换直接吸附到转场那一帧，制造“画面一变、和声同时翻页”的大片体感。

### 1. 全片转场 T1–T7 配音与提前量（对应 `07_大标题与大片感.md`）

| 转场代号 | 画面手法 | 搭配声音（合成配方） | 音频起始提前量（60 fps） | 峰值/冲击对齐帧 | 混音电平（相对底乐静态） |

### 2. 分轨到母带处理顺序（施工方固定流水线）
所有处理均在 `float64` 内部运算，最后一步再量化输出 `24-bit PCM WAV`（供视频封装为 `AAC 320 kbps / 48 kHz`）：

1. **人声预整备（`voice_bus`）**：高通 `85 Hz`（4 阶）→ 降噪（出镜段轻度去稳态噪）→ 逐段响度归一至 `-14.5 LUFS` → 轻压缩 `pedalboard.Compressor(threshold_db=-20.0, ratio=2.2, attack_ms=10.0, release_ms=90.0)`（增益衰减控制 `2–3 dB`）→ 去齿音动态衰减 `6500 Hz`（超阈值压 `2 dB`）。
2. **底乐分轨合成与让位（`bed_bus`）**：五轨合成 → 各轨应用第二节混响/饱和 → 应用第三节静态 EQ 挖空 → 读入 `voice_bus` 离线计算侧链曲线并按子轨权重压低 + 驱动 `arp`/`pad` 动态 EQ → 归一化底乐静态段落短时响度至 `-24.0 LUFS`。
3. **W 段原曲整备（`w_bus`）**：按 `master_v1.json` 裁剪并对拍 → 段内响度拉齐至 `-12.5 LUFS` → 预叠 2 小节与淡出 1 小节施以逐章表规定的 `LPF` 扫频、`-20/-18 dB` 衰减与 `2400 Hz -4 dB` 挖空。
4. **音效与卡点轨（`sfx_bus`）**：按第四节提前量排布转场 T1–T7、Boom、Riser 与零件物理音效，施以低切 `35 Hz` 与峰值保护 `-4.0 dBTP`。
5. **母带总线（`master_mix`）**：四总线求和（`voice_bus + bed_bus + w_bus + sfx_bus`）→ 母带胶水微压 `pedalboard.Compressor(threshold_db=-10.0, ratio=1.5, attack_ms=30.0, release_ms=180.0)`（全片峰值处增益衰减 `≤ 1.0 dB`）→ **4× 过采样真峰值限幅器** `pedalboard.Limiter(threshold_db=-1.0, release_ms=60.0)` → 用 `pyloudnorm` 二次实测全片积分响度，若偏离 `-14.0 LUFS` 超过 `±0.3 LU`，做一次性线性增益微调后重过真峰值限幅器。

### 3. 自动化验收门槛（11-23 施工完成必跑机检）
施工脚本跑完后自动输出 `G:/cdk20/work/audio/bed/qc_report.json`，全部 6 项通过才算交活：
1. **全片积分响度**：`-14.5 ≤ I ≤ -13.5 LUFS`，且真峰值 `TP ≤ -1.0 dBTP`。
2. **底乐让位实测**：任抽 10 段 VO 与 5 段 ON-CAM，人声活跃帧上 `ShortTerm(voice) - ShortTerm(bed)` 必须 `≥ 15.0 LU`（VO）与 `≥ 17.5 LU`（ON-CAM）。
3. **零硬切检查**：全片分轨（除刻意设计的 0 ms 砸入点 W0 起始 / W1 0.50 s / W4 闩落外）相邻 `10 ms` 窗跳变不超过 `6 dB`，全片无直流偏移（`|DC| < 1e-4`）、无 `NaN/Inf`。
4. **静音段核验**：5-06 停转后静默区、8-04 全静段、W5 至彩蛋间 `1.50 s` 黑场，底乐 RMS 必须 `< -90 dBFS`。
