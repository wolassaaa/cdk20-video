# 失落星船：马拉松 美术参考 v2 · 2026-10-31

这是香港浸会大学 SCIE1007 本科小组课程作业的美术笔记，不是科研项目。这里只分析一款公开发行游戏的平面设计方法，用来给一条科普视频做视觉。

**结论**

- 第一版看不出参考，原因有两个。研究只读了文字，没看图；我们自己加的几条规矩又把剩下的影响压没了。
- 导演定下的规矩只有两条：调色板，和不闪。其余几条都是我们自己写的，可以改。
- 这轮看了真实画面，重做了静帧 03、04、06、09。前后对比在 `styleframes/S2plus/stills/m/前后对比.jpg`，新图的 4K 版在 `stills/m/4k/`。
- 新图没有用它的标志、字体、界面布局和素材。参考图也没有存到本地。
- 还有七件事要导演定，见第 6 节。

## 1. 看了什么

- **Kurppa Hosk 的案例页和他们自己的视频。** 这是平面视觉最完整的来源，品牌图、海报、动效都在。
- **Fonts In Use 的条目。** 用来确认字体搭配的类型，比如超宽黑体、超窄黑体、衬线标题和等宽正文。
- **Stash 对 Antibody 的报道。** Patrick Clair 谈到图形本身克制，用色却放得很开。

Vimeo 播放器提示无法验证连接，我没有绕过，改看 Kurppa Hosk 自己放的视频。所有图都只在浏览器里看，没有保存。

## 2. 它实际在做什么

| 手法 | 真实画面里的样子 | 第一版的情况 |
|---|---|---|
| 整屏纯色相撞 | 大面积纯色直接撞在一起，不用渐变过渡 | 我们大多是黑底，纯色只在少数几屏出现 |
| 把生物画成扫描数据 | 身体扫描带等高切片，蛾子放进线网，手的黑影压在巨型图形上 | 蛋白是点画，气质偏科学插图 |
| 三维主体压在巨型平面图形上 | 主体前后都有出血的平面图形，形成层次 | 主体和图形分开摆，条码在下方当图例 |
| 极端字宽 | 超宽黑体和超窄黑体占满版面，衬线标题配等宽正文 | 字号克制，最大的字也只是"大" |
| 边缘的小数据群 | 角落有小字、十字阵、套准标记、跑马条 | 几乎没有 |
| 像素语言 | 阶梯边、马赛克溶解、点阵面板配小标签 | 只有 W3 的点阵 |
| 点云主体配超窄字 | 银色点云半身配细高字 | S04 接近，但字太弱 |
| 动效 | 色块翻转转场，快切一串记号，落在一张密集拼贴上 | 还没试 |

## 3. 第一版为什么显不出来

| 规矩 | 谁定的 | 这轮怎么处理 |
|---|---|---|
| 调色板：黑、血红、蓝、骨白、克莱因蓝 | 导演 | 不动 |
| 不闪，不加逐帧颗粒 | 导演 | 不动 |
| 同一帧最多两条手法 | 我们自己 | 这四张放开 |
| 像游戏宣传图就退一步 | 我们自己 | 去掉。判断标准改成信息是否读得清 |
| 一屏一色 | 我们自己 | M09 放开，红蓝同屏，等导演定 |
| 铺色只有 6 次 | 我们自己 | M03 和 M04 各加一屏整色，等导演定 |
| 不拿密度 | 我们自己 | 改成：要读的字保持少，密度放在不需要读的地方 |
| 六种字设置 | 我们自己 | 加一种展示字 Anybody 和一种小字，只用于这四张 |

证据牌规则没有改。骨白是实测，蓝是 AI，空心蓝是我们的对接，虚线是示意。

## 4. 四张怎么改

| 静帧 | 学的方法 | 我们自己的内容 | 数据依据 |
|---|---|---|---|
| M03，剧本 3-08 | 整屏纯色，巨型黑体，出血的黑色形状，十字阵 | 骨白代表实测，所以整页都是已测到的事。缺的那块是钥匙孔，直接切穿纸面 | 36/52 这 52 格对应 Feng 2011；右边缘是 346 个真实字母 |
| M04，W2 | 把生物画成扫描数据，三维主体压在巨型图形上 | 线宽等于光照乘 pLDDT 置信度，低于 70 的区域只剩断线。346 根条码绕成圆环出血 | AlphaFold DB v6 的全部 2,735 个重原子和 346 个 pLDDT |
| M06，W3 | 点阵面板，极端字宽 | 这个数字由它自己组成：恰好 8,918 个点填满 8,918 的字形 | 成图上逐个数过，1080p 和 4K 都是 8,918 |
| M09，W4 | 纯色相撞，巨型数字，十字阵 | 误差和数值同样大，不让 33.4 看起来比实际更确定。口袋用和 M04 相同的刻线 | Ren 2023 Fig. 9A；口袋来自我们自己的对接 |

## 5. 这次没有拿的

- 它的标志、字体、界面布局、素材和酸绿。
- 衬线大标题、警示条纹、跑马条。这些很容易让人直接想到它。
- 马赛克溶解和色块翻转。动起来才能判断，而且要先确认不违反不闪的规矩，下一轮再试。

## 6. 要导演定的

1. **红蓝同屏。** M09 的蓝色口袋紧贴血红色块，这是早报里 S09 的开放决定。
2. **新展示字。** Anybody 是否进入全片的字体系统。它不再受六种字设置的约束。
3. **S3 的整屏骨白。** 第一版 S3 是黑底，M03 改成整屏骨白。
4. **W2 的标签数量。** 剧本写只留一个标签，M04 多了两行 pLDDT 小字和残基编号。残基编号算条码刻度，那两行小字可以删。
5. **F24 这句话。** M03 把 "no one had measured CDK20's shape" 放得更醒目。这句台词本身还没批。
6. **要不要铺开。** 其余 10 张是否按这个方向重做。
7. **W2、W3 的动态。** 这两段现在停在第一版静帧上。采用新图的话，结尾都要改。

## 7. 还没验证的

- 这四张都只是静帧。刻线锁在模型空间里，理论上转动时不会爬，但还没有实测。
- 刻线蛋白的 4K 单帧约 4 秒，只测过这一帧。4K60 排产要按动态实测再算。
- Anybody 目前在渲染时从 Google Fonts 在线加载。交片前要把字体文件和许可文件核一遍。
