## 1. 热成像 / 伪彩

- **Richard Mosse《Incoming》**（2017）：用军用热像仪拍难民营地，做成三屏影像装置，同期还有照片系列《Heat Maps》。要注意，他的成品是**单色**的（白热灰阶），不是伪彩。我们借的是"用热量看人"的观念：人只剩下体温，看不清是谁。
  - [Art21 介绍](https://art21.org/artist/richard-mosse/) · [BFI 评论](https://www.bfi.org.uk/sight-and-sound/reviews/incoming-richard-mosses-heat-map-images-dazzle-political-darkness) · [NGV](https://ngv.vic.gov.au/multimedia/richard-mosse)
- **导演的参考《Red Knot Chain》**：伪彩、颗粒、高光边缘烧出黄绿色的一圈，管子看起来像有体积。
- **能拿来做什么**：热量 = 活着。肝一开始是暖的（红到黄），每"走掉一个人"，就有一块热点冷下去，从黄退到红、蓝、黑。这比灯熄灭更冷、更现代，也不像游戏。
- **做法**：Remotion 里先画灰阶的"热量图"（模糊的形状），再用 SVG 的 `feComponentTransfer` 映射成伪彩色带。一个滤镜就够，粗稿很快能出来。TD 版本同理（Lookup TOP）。

## 2. X 光 / 血管造影

- **Nick Veasey**：英国艺术家，自己有 X 光工作室，拍花、拍日用品。花的 X 光片里能看到它自己的"血管系统"，也就是维管束。[Smithsonian](https://www.smithsonianmag.com/arts-culture/x-ray-art-deeper-look-everyday-objects-180949540)
- **Hugh Turvey**：把可见光和 X 光叠在一起，自己叫 "xogram"，大多上了颜色。[Trendland：X 光的花](https://trendland.com/flowers-x-rays-by-hugh-turvey/)
- **能拿来做什么**：导演想要"一根血管先往上走，再分出很多枝"，这**本来就是血管造影的样子**。造影剂打进去，亮的前锋沿着一根血管往前跑，再一级级灌满整棵血管树，最后整个器官被点亮。这样分枝出现得有道理，不用硬编。

## 3. 起雾的玻璃 / 呼吸

- **Julie Rrap《Blow Back》**（2018，Roslyn Oxley9 画廊）：几位艺术家对着玻璃呼气，在雾上留下痕迹。展览文字里还提到 Gabriel Orozco 的《Breath on Piano》（1993），是黑色钢琴漆面上的一口哈气。[展览页](https://www.roslynoxley9.com.au/exhibition/blow-back/n4dsn)
- **Jill Reynolds《The Shape of Breath》**（MIT List，1997）：用玻璃和呼吸给"看不见的东西"一个形状，也讲呼吸和语言的关系。[MIT List](https://listart.mit.edu/exhibitions/jill-reynolds-shape-breath)
- **能拿来做什么**：哈气会散 = 生命会消失。手指在雾上写的字会往下淌水，水痕本身就像血管。
- **放在哪**：比起 W0，更适合 **W1 片名卡**。片名用手指写在起雾的玻璃上，剧本里 W1 结尾本来就是"墨点溅开变成雨"，雾玻璃加雨正好接上 S2。

## 4. 心跳和灯

- **Rafael Lozano-Hemmer《Pulse Room》**（2006，2007 年威尼斯双年展墨西哥馆）：天花板上挂几百个灯泡，观众握住传感器，自己的心跳就变成一个灯泡的闪烁，新的心跳把旧的往后推。灵感之一是电影《Macario》：每个人是山洞里的一根蜡烛。[MACM](https://macm.org/en/collections/oeuvre/pulse-room/) · [艺术家手册 PDF](https://www.lozano-hemmer.com/texts/manuals/pulse_room.pdf)
- **能拿来做什么**：四个人不是四颗"心"，而是四个**按心跳闪的光点**，跳着跳着停了。比游戏血条庄重，又比静止的灯有生命感。

## 5. 红线 = 血管（装置）

- **盐田千春（Chiharu Shiota）**：红线织满整个房间。评论常把红色读成血、把线网读成血管和神经，也连到东亚"红线"的说法。[Artnet 报道（转载）](https://www.art-19.com/news/artnet-how-chiharu-shiota-weaves-a-web-of-memory-and-history-thread-by-thread) · [Hammer Museum](https://hammer.ucla.edu/exhibitions/2023/hammer-projects-chiharu-shiota)
- **Charlie Murphy《Blood Vessels》**：用旧的科学玻璃器皿烧成静脉、动脉、心瓣膜。[Science Gallery Dublin](https://dublin.sciencegallery.com/blood-1/blood-vessels)
- **能拿来做什么**：血管不画成"线条"，而是画成**有体积、有光泽的东西**，比如玻璃管里的红液体，或者绷紧的红线。这正是参考图里管子好看的原因。

## 6. 镜头进入身体

- **Mona Hatoum《Corps étranger》**（1994，蓬皮杜藏）：用内窥镜拍自己身体内部，投在一个圆筒小房间的地面上，配呼吸和心跳声。[蓬皮杜](https://www.centrepompidou.fr/en/ressources/oeuvre/cdj4RE)
- **Pipilotti Rist《Pickelporno》**（1992，MoMA 藏）：广角小摄像头贴着皮肤拍，颜色推得极饱和。[MoMA](https://www.moma.org/collection/works/118392)
- **能拿来做什么**：导演说的"镜头一路跟着往前走"，可以拍成内窥镜视角：圆形画框，镜头在管道里往前推，四周是湿润的红色。然后"拔出来"拉远，才看到整体。

## 7. 数据的那一面

- **池田亮司《data.anatomy [civic]》**（2012，柏林 Kraftwerk）：把本田 Civic 的设计数据拆成黑底白字的影像，偶尔闪一下红。[It's Nice That](https://www.itsnicethat.com/articles/ryoji-ikeda-data-anatomy)
- **能拿来做什么**：PREDICT / DESIGN / TEST 不用血管拼，做成扫描影像角落里的**数据标注**，像医学影像四角的那种文字。这就是"计算机"的声音，用我们的电青等宽字。

## 我的推荐组合：造影 → 热成像

| 时间 | 画面 | 来自 |
|---|---|---|
| W0 第 1 下 | 黑底，一个亮点被"打进去"（造影剂） | 2 |
| W0 第 2 下 | 亮的前锋沿一根血管往上跑，镜头紧跟（内窥镜 / 造影的感觉） | 2、6 |
| W0 第 3 下 → 1-01 开头 | 镜头拉远，造影剂一级级灌满血管树，整个肝像 X 光片一样亮起来；角落淡出 `PREDICT · DESIGN · TEST` 数据标注 | 2、7 |
| 1-01 | 画面切成热成像伪彩：肝是暖的；四个跳动的热点（按心跳闪）一个个冷下去，从黄退到蓝 | 1、4 |
| W1 | 片名写在起雾的玻璃上，雾散、下雨，接 S2 | 3 |

为什么这样组合：

- 导演原来的创意都保留了：一根血管往上走、拉远后才分枝、最后变成肝。现在它们有了真实的医学理由（造影）。
- 冷暖的反差就是全片的"人暖、机器冷"：热成像管生命，电青数据管计算机。
- 四个人用"冷下去"来讲，克制、现代，不卡通。
