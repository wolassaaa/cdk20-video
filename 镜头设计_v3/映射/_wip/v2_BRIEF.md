# v2 美术方向：铜版说明书页（4-03 / 4-10 重做用）

HKBU SCIE1007 课程作业的科普视频。这份文件是**唯一的视觉标准**。v1 被导演否掉，原因是三条：3D 零件像剪贴画贴在米色纸上、没有版面结构、大片空白。v2 全部按下面这套做。

## 0. 一句话方向

把每一页做成**一张印出来的说明图版**（想象 1960 年代仪器手册或博物馆展板的铜版画）：暖纸、铁胆墨、发丝细的规矩线、手绘的主角线条、一块网点照片插图、带编号的引注图例、一条数据刻度。红色只做三处手批，别的地方一点红都不给。

关键词：**线描、排线阴影、网点、细线框、小字图注、编号引注、留白成块不成洞**。

## 1. 为什么 v1 丑（改的时候逐条对着改）

1. `Part` 的 3D 零件当主角，直接浮在纸上 —— 光打得很足的塑料感，和纸、和细线都不在一个世界。
2. 满页只有「零件 + 几行字」，没有铅字时代的道具体系：没有页眉、没有细线、没有图注、没有编号、没有刻度、没有角标。
3. 字全是 Serif 一个字号段（24–30），没有层级；标签悬空，没有引线，读的时候不知道指哪儿。
4. 构图是散的：主角偏小、没有动势；空白是一整块洞，不是被结构切开的块。
5. 红色用得太随便（红虚线、红圈、红笔、红叉一起上），重点反而不重点。

## 2. 材质与线条

- 颜色只用四个：`PAPER #EDE9DF`、`INK #1F1E1C`、`SOFT #6E6B63`、`RED #C8102E`。除此之外不许有第五种颜色（网点、排线只能用 INK 的透明度）。
- **线重三级**（必须同时出现）：
  - 发丝：`1.2px`，透明度 0.45 —— 规矩线、引线、刻度、图例分隔线。
  - 中锋：`2.4px` —— 次要图形的外轮廓。
  - 主角：`5.5px` —— 主角轮廓；再叠一条 `1.6px`、偏移 `(1.6, 1.6)`、透明度 0.35 的影子线，做出「墨吃进纸里」的双线感。
- **手绘抖动**：所有手画路径（主角轮廓、圈、箭头、叉）都要带 ±0.8–1.5px 的抖动。做法：把路径按点采样，每点加 `sin(i*7.3)*1.1` 之类的确定性偏移。不要用完美的圆弧和直线。
- **排线阴影**：需要暗面时用 45° 平行线，间距 7px、粗 1.1px、INK 透明度 0.5，裁在形状里。不要用灰块或渐变。
- **网点**：只用在「照片插图」上。做法：`background-image: radial-gradient(circle, rgba(31,30,28,.85) 0.9px, transparent 1.05px); background-size: 3.6px 3.6px;` 叠在零件图上，整块透明度 0.28。这是让 3D 零件「印」进纸面的唯一办法。

## 3. 版面（硬坐标，两页共用）

- 画面 1920×1080。纸框沿用 `<PageFrame />`（x 40–1880，y 34–1036）。
- **页眉**：左边 kicker（18px、字距 3px、全大写、SOFT），右边 folio（18px、SOFT、右对齐到 x 1820）；页眉基线 y 96。页眉下 **1.2px 细线，y 140，x 96→1820**。
- **内容区**：x 96–1820，y 176–984。
- **页脚**：**1.2px 细线，y 1008，x 96→1820**；出处行照旧在 y 1046、17px。
- **栏格**：12 栏，起点 96，栏宽 130，栏距 14（12×130 + 11×14 = 1714，右端 1810）。
- **基线**：44px。所有文字块的顶边落在 `176 + 44k` 上。同一行的元素共用一条基线。
- **留白**：任何一块连续的空白不许大过 300×300。填空的工具按优先级：图例、刻度、细线、编号、角标、图注 —— **不许为了填空加旁白里没有的内容**。

## 4. 字

只两族：`fontFamily: "Serif"`（Instrument Serif）与 `<Pen>`（Caveat 红色手写）。

| 用途 | 字号 | 说明 |
|---|---|---|
| 标题 | 54 | INK，写在页眉左，kicker 在它上面一行 |
| 小标题 / 图注抬头 | 28 | 全大写、字距 2px、SOFT |
| 正文标签 | 24 | INK |
| 图例条目 | 22 | INK |
| 页眉页脚 / 出处 | 18 / 17 | SOFT |
| 手批 | 34–40 | 只走 `<Pen>`，每页 ≤ 3 处 |

- 图注统一格式：`FIG. 1 — the model`（编号 + 破折号 + 旁白原词）。
- 画面上每个英文字仍然只能来自这段旁白或剧本 Visual 行。图注里的 `FIG.`、编号、`1 ·` 这类**仪器性文字**（版式零件）可以用，不算内容。

## 5. 道具体系（每页至少用 5 种）

1. **编号引注**：34px 空心圈（1.6px 环）+ 15px 数字，压在图形上；一条 1.2px 引线，靠图形那头一个小圆点（r 2.5）。
2. **图例栏**：右栏，一行一个条目：编号圈 + 文字 + 该行下面一条 1.2px 细线（透明度 0.35）。
3. **刻度 / 数据条**：带端刺的细线（ticks 6px），下方小字标签。不许编数字，只画位置关系。
4. **角标**：比如 `PLATE 4-03`、`CH. 4`、`×1`，18px 全大写。
5. **印章**：−6° 旋转、3px 红框、30px 红字（只用在「blocked」这类词上）。
6. **照片插图**：圆形或圆角矩形窗口，4px INK 边 + 4px 纸色内衬，里面放 `Part` 图 + 网点，下方一行 20px 斜体图注。

## 7. 动（时间不变）

- 事件表已经定死并通过 validate：4-03 24 个事件、4-10 26 个事件。**不许改事件表**，画面全部挂 `E.<id>.s / .l / .e`。
- 每个动作在它挂的词说出口时到位。
- 手绘线的出现一律用 `stroke-dashoffset` 推进（从 0 到 1），别用缩放弹入。
- 字用 `<Write>`；只有印章可以用缩放落章。
- 整段不许有 2.8 秒以上静止；同一句里相邻两个落点不超过 90 帧。
- 红色每页 ≤ 3 处高价值位置。

## 8. 自检（每轮都做）

1. 渲染关键帧（用瘦 public，见第 9 节），**逐张 read_image 看**，对照下面 7 条打分，任何一条低于 7 就改。
2. 数值检查：不许有两块元素框相交；字不出页框；主角占比 ≥ 35% 内容区高度。
3. 改完再渲染一次，至少 3 轮。

**7 条评分口径**（每条 1–10）：
1. 第一眼：有没有一个明确的主角，有没有一条清楚的视线动势。
2. 密度：空白是不是被结构线/图注/刻度切开成块，有没有 >300×300 的洞。
3. 线条：线重是否 ≥3 级，是否有手绘抖动，暗面是否用排线。
4. 字：字号层级 ≥4，有没有小字图注和页眉角标。
5. 红：是否只在 ≤3 处、且都在关键处。
6. 印刷感：网点照片插图、双线、细线框是否成立。
7. 克制：装饰不抢主角，信息不重复。
