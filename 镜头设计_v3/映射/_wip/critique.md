## 4. 「贴纸感」的代码根源（改 v2 时优先动这几行）

**Manual403.jsx**
- **L8 + L60** `<Part name="lock">` —— 彩照模型直接浮在纸上（`_c.png` 无遮罩、无网点），高光和蓝色塑料感是"贴纸"的第一来源；`gate={[0.5,1]}` 还让颜色从浇口漫开、`filter: brightness(1.7)` 造出一圈亮边（kit L37），更像"正在贴上去的贴纸"。
- **L96–97** 放大圈是 `<div>` + `4px solid` + `borderRadius` + `background #F4F1EA` —— 一个描了边的圆纸片；**L100** 平涂 `rgba(36,62,170,.20)`（渲成 `#CACCDD`）是第五种颜色；**L102–104** 白填锁孔 + `#2A3F9E` 4px 边 = 矢量图标。
- **L110–112** 尾巴 = 18px 折线 + 每点 r11 圆点 = 串珠。
