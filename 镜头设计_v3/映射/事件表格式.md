# 事件表格式（events/<段>.json）

HKBU SCIE1007 课程作业的科普视频。这一页说明"词 → 画面事件"表怎么写。表只写"哪个东西、做什么、从哪个词起、到哪个词停"，不写帧号。帧号由 `resolve.py` 按总表（`master_v1.json`，录音实测的词时间）算出来，写到 `keys/<段>.json`。

## 文件

- 一段一个文件：`映射/events/<段>.json`。出镜对话组的文件名把 `+` 换成 `_`，例如 `1-05_1-06_1-07.json`。
- 顶层字段：`schema`（固定 `cdk20.events/1`）、`group`（段号）、`tool`（blender / remotion）、`note`、`holds`（有意停住的段内帧区间，可空）、`events`（列表）。

## 一个事件

```json
{"id": "bill0", "obj": "bill_0", "verb": "eject",
 "at": {"word": "cost", "off": 0}, "lead": 60,
 "until": {"dur": 0}, "ease": "out", "means": "cost：第 1 张钞票顶出落下"}
```

| 字段 | 必填 | 含义 |
|---|---|---|
| id | 是 | 段内唯一，程序用它取帧 |
| obj | 是 | 动的东西（Blender 物体名或 Remotion 图层名） |
| verb | 是 | flow / grow / eject / retract / appear / move / camera_to / morph / snap 九个之一，插座段另有 plug_in / plug_out / eject_swap / twist / clamp / power_on / power_off，叠化用 dissolve，含义见下面"动词" |
| at | 是 | 落点，也就是这个词说出口、东西到位的那一刻。`{"word": 词, "off": 偏移帧}`；词可以写 wid（`1-08.w018`）、原词（`cost`）或第几次（`and#2`）。也可以写 `{"event": 前面某个事件的 id, "off": n}`，跟在前一个事件后面 |
| lead | 否 | 落点前提前多少帧起动，默认 0 |
| until | 否 | 动作持续到哪里。`{"word": 词}` 是那个词说完，加 `"edge": "start"` 就改成那个词开口；`{"sentence_end": true}` 到本句句尾，也可以写句号 `"1-08.s3"`；`{"dur": 帧数}` 从落点起算持续多少帧；`{"event": id}` 和那个事件同时结束。都可以带 `off`。不写就在落点结束 |
| ease | 否 | linear / in / out / inout / hold，默认 inout |
| means | 否 | 一句话说明它在讲什么，给人看 |
| seg | 否 | 多段组里只在这一段找词 |

算出的帧：`f_land = 词开口帧 + off`，`f_start = f_land − lead`，`f_end` 由 until 决定。三个都是段内 60 fps 帧。`keys/` 里另给片内帧 `F_* = 段在片里的起点帧 + f_*`。

## 动词

全片七个动作（滑、长、拔、讲、拼、回、变，见 `审片/总管/全局统筹_板件与资产_v1.md` 第三节）和动词的对应。morph、snap 是 11-17 做大板样片时加的。`审片/总管/动效打磨要点_v1.md` 另有要求：两个动作的起帧至少错开 2 帧，止帧也是；eject 的 lead 不少于 2 帧（预备），until 不少于 12 帧（余振）。

| 动词 | 动作 | 三个帧的含义 |
|---|---|---|
| camera_to | 滑 | `f_start` 起动，`f_land` 到机位；有 until 时 `f_land → f_end` 慢慢收住，到 `f_end` 停稳 |
| grow | 长 | `f_start` 第一层料从浇口出来，`f_end` 长满；`f_land`（词开口）时已经能认出是什么 |
| eject | 拔 | `f_land` 浇口断开、零件弹起（这一帧配"哒"声）；`f_end` 回弹一次后停稳，浮在板上方 |
| move | 讲、回 | 浮着的零件转、飞到别处、落回空位：`f_start` 起动，`f_land` 到位 |
| morph | 变 | `f_start` 表面变软发亮、开始流动；`f_land` 新形状成形；`f_end` 凝回硬的亮面塑料 |
| snap | 拼 | `f_start` 定位销对准孔、开始插入；`f_land` 卡到底（这一帧配"咔"声）；`f_end` 整体下沉后回位。两件之间留接缝，不融合 |
| plug_in | 插 | 插座比喻（06_插座比喻.md 4.0，11-20 登记）：插头沿插孔轴插入，`f_land` 到底（最后 6 帧减速，0.1 mm 小回弹到 `f_end`） |
| plug_out | 拔出 | 插头被弹簧顶出、沿轴退出：`f_start` 起动，`f_land` 离开孔口，`f_end` 停到待机位 |
| eject_swap | 顶替 | 假插头进来时真插头被顶出：`f_start` 弹出，`f_land` 让开孔口轴线，`f_end` 回到待机位停稳 |
| twist | 拧 | 插头绕轴拧卡口：`f_start` 起拧，`f_land` 到 90°（2° 过冲，"咔"），`f_end` 回到 90° 停稳 |
| clamp | 扣 | 红色卡扣扣上：`f_land` 扣到位（"咔"），`f_end` 余振停 |
| power_on / power_off | 通电 / 断电 | 灯、光包、活塞、细胞四样一起变：`f_start` 开始变，`f_land` 到新状态，`f_end` 稳住 |
| dissolve | 叠化 | 一个画面溶成另一个（三维钻取：玩具溶成真实结构）：`f_start`=`f_land` 开始溶，`f_end` 溶完；退出用同一个动词，`f_start` 开始退、`f_end` 退完。check_sync 的帧率检查把这段的"混帧"算设计渐变 |
| appear | | 二维元素（字幕、出处行、印字）出现 |
| flow | 流 | 料在料杆里走：一个鼓包从 `f_start` 滑到 `f_land`（到浇口前），镜头跟着它；旧表里是模具流道的料流 |
| retract | | 旧的模具语言（顶针收回），旧表还在用 |

## 规则（validate_events.py 检查）

1. 格式：id 唯一，verb 和 ease 只能用上表里的值。
2. 引用的词在总表这段里存在。
3. 顺序：`f_start ≤ f_land ≤ f_end`，都在段内；until 不能早于 at；`at.event` 只能引用写在前面的事件。
4. 每句说话期间，没有任何事件在动的时间不超过 90 帧（1.5 s）。
5. 每句最后一个事件结束不早于句尾前 2 帧（动作不早停）。

## 迁移来的表

`migrate_beats_v8.py` 自动写的表顶层带 `"migrated": "migrate_beats_v8"`。其中 `obj: footage` 的事件是旧动画的变速锚点：`value=[源片起秒, 源片止秒]`，意思是这段帧里播放源片的这一截。它们可以用来原生重渲旧动画，但不算语义事件，要按剧本补写"说到哪个词、哪个东西出现"。重新迁移不会覆盖没有这个标记的手写表。
