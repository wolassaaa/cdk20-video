HKBU SCIE1007 课程作业的科普视频。这份讲三个 agent（Claude 主线、DS、Codex）在同一个项目文件夹里怎么互发消息、怎么占文件，不涉及片子内容。

## 2. 每个 agent 的规矩

1. **开工先收信**：每次开始一步工作前，`fetch_inbox`（自己的名字）看有没有新信。
2. **改文件前先占**：要改的文件或文件夹先 `file_reservation_paths`（`exclusive=true`，`ttl_seconds` 按预计用时给，比如 3600），被别人占着就别改，发信问。改完 `release_file_reservations`。占用替代了协作约定第 2 条"先留言等回复"的那一步。
3. **要对方回的事**发信时加 `ack_required=true`，收到的人用 `acknowledge_message` 确认。
4. **同一件事用同一个 thread_id**，比如 `S5-410`、`GPU`、`REVIEW-1109`。
5. **显卡**：开 Blender 前在 thread `GPU` 发一封信，写预计时长和结束时刻（香港时间）。排队仍然靠 `gpu_slot.sh`。
6. **导演拍板的事**照旧写进 `交接_4-10_S5/02_协作约定.md` 的留言和 `工作记录.md`；信箱只放日常沟通。
7. 和导演说话用中文；信件也用中文。

## 3. 导演怎么看

- **实时面板（终端）**：在终端里敲 `am`，出现选项时按回车（attach read-only，只看不管），第 1 页是实时事件流，按 `2` 看信、`3` 看对话、`4` 看 agent、`6` 看文件占用，`q` 退出；退出不影响服务。
- **网页**：浏览器打开 http://127.0.0.1:8765/mail/ ，能看到所有信、占用和搜索，也能以"监督者"身份给 agent 发信。网页不是实时的：总收件箱说是 45 秒自动刷新，11-09 实测一分多钟没动，点页面上的刷新按钮马上出来。

## 4. 服务没开怎么办

信箱服务要一直开着，三边才连得上。开机后它不会自己起来：

- 双击 `镜头设计_v3/协作信箱/start_agent_mail.cmd`；已经在跑会提示 already running。
- 查活：打开 http://127.0.0.1:8765/health/liveness ，显示 `{"status":"alive"}` 就好。
- 信和数据库存在 `C:/Users/woola/.local/share/mcp-agent-mail/`，不在项目里，不进 GitHub。
